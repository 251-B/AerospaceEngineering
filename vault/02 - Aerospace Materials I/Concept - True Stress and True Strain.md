# Concept: True Stress and True Strain

> **Key idea:** the true stress uses the instantaneous area and the true strain sums the length changes, so the true curve keeps rising after the engineering curve has peaked.

## Definition and formulas
- The dimensions change during the test: $\sigma_{\text{real}} > \sigma_{\text{eng}}$ and $\varepsilon_{\text{real}} < \varepsilon_{\text{eng}}$ [Session 11 Slide 37].
- **True stress:** $\sigma_r = \dfrac{F}{A_i} = \sigma_{\text{eng}}\dfrac{A_0}{A_i}$ [Session 11 Slide 37].
- **True strain:** $\varepsilon_r = \displaystyle\int_{L_0}^{L}\frac{dL}{L} = \ln\frac{L}{L_0}$ [Session 11 Slide 37].
- **Before necking** (volume constant, $l_0A_0 = l_iA_i$): $\sigma_r = \sigma_{\text{eng}}(1+\varepsilon_{\text{eng}})$ and $\varepsilon_r = \ln(1+\varepsilon_{\text{eng}})$ [Session 11 Slide 38].
- **After necking:** $\sigma = \sigma_{\text{eng}}A_0/A_i$ and $\varepsilon_r = \ln(A_0/A) = 2\ln(D_0/D)$ [Session 11 Slide 38].
