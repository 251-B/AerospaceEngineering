# Problem Set - Advanced Maths Problem Bank

> 22 exam-style problems written for the portal (not official exercises), each solved with the four phases of the repository and checked with SymPy (`scripts/am_bank/pnn.py`). They imitate the structure of the official papers analysed in [[Exam Analysis - Official Papers 2011-2025]]. Hub: [[Advanced Maths MOC]]. Builder: [[Tool - build_maths_bank]]. Web: `subjects/advanced-maths/extra-problems/` and the Exam simulator.
