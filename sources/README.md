# 📚 Repositorio de Fuentes Originales (Ground Truth)

Este directorio alberga los materiales oficiales, diapositivas, boletines de problemas, exámenes de la cátedra y guiones de laboratorio de 2º curso del Grado en Ingeniería Aeroespacial. Sirve como la **única fuente de verdad** autorizada para nutrir la bóveda de Obsidian (`vault/`) y el portal de estudio (`subjects/`).

---

## 📁 Estructura Modular por Asignatura (5 Carpetas por Materia)

Cada materia cuenta con una partición estandarizada en 5 carpetas funcionales:

```text
sources/<asignatura>/
├── teoria/       # Mega PDF oficial con el manual completo o libro de apuntes de la asignatura
├── slides/       # Diapositivas y presentaciones en PDF específicas de temas o bloques de clase
├── problemas/    # Boletines oficiales de ejercicios, hojas de problemas y seminarios
├── examenes/     # Exámenes oficiales de convocatorias anteriores (parciales, finales, soluciones)
└── Labs/         # Guiones de prácticas de laboratorio, datos experimentales y normativas
```

## 📌 Directrices de Ingesta y Rigor Académico

1. **Rigor y fidelidad absoluta (Cero alucinaciones):** Toda ecuación, hipótesis, convención de signos y enunciado debe extraerse textualmente de los documentos depositados en estas carpetas.
2. **Formatos soportados:** PDF, Markdown (`.md`), Texto plano (`.txt`), Presentaciones convertidas a PDF e Imágenes de diagramas (`.png`, `.jpg`).
3. **Trazabilidad:** Cada concepto en Obsidian y cada módulo web citará el documento y la página/diapositiva de referencia exacta.
