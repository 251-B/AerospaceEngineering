Problem 2.1

Direct Integration General Solutions (5 Equations)

Direct Quadrature • Antiderivatives • Partial Fractions
Phase 1: Problem Statement & Hypotheses

Enunciado: Find the general solution of the following equations by direct integration:

  1. (i) $y' = e^{3x} - x$
  2. (ii) $y' = 1/x$
  3. (iii) $y' = x e^{x^2}$
  4. (iv) $y' = \frac{1}{1 - x^2}$
  5. (v) $y' = \frac{1}{x(1 - x)}$
Phase 2: Fundamental Formulation

In all 5 sub-problems, the derivative $y'(x) = f(x)$ depends solely on $x$. By the Fundamental Theorem of Calculus: $$ y(x) = \int f(x) \, dx + C $$ We identify suitable integration techniques for each: direct primitives, $u$-substitutions, and partial fraction decompositions.

Phase 3: Step-by-Step Derivation

(i) $y' = e^{3x} - x$:
$$ y(x) = \int (e^{3x} - x) \, dx = \int e^{3x} dx - \int x dx = \mathbf{\frac{1}{3} e^{3x} - \frac{x^2}{2} + C} $$

(ii) $y' = 1/x$:
Defined for $x \neq 0$: $$ y(x) = \int \frac{1}{x} \, dx = \mathbf{\ln|x| + C} $$

(iii) $y' = x e^{x^2}$:
 Substitute $u = x^2 \implies du = 2x dx \implies x dx = \frac{1}{2} du$: $$ y(x) = \int x e^{x^2} \, dx = \frac{1}{2} \int e^u du = \frac{1}{2} e^u + C = \mathbf{\frac{1}{2} e^{x^2} + C} $$

(iv) $y' = \frac{1}{1 - x^2}$ ($x \neq \pm 1$):
 Partial fraction decomposition: $\frac{1}{(1-x)(1+x)} = \frac{A}{1-x} + \frac{B}{1+x} \implies 1 = A(1+x) + B(1-x)$. Setting $x = 1 \implies A = 1/2$; setting $x = -1 \implies B = 1/2$. $$ y(x) = \frac{1}{2} \int \frac{dx}{1-x} + \frac{1}{2} \int \frac{dx}{1+x} = -\frac{1}{2} \ln|1-x| + \frac{1}{2} \ln|1+x| + C $$ $$ \mathbf{y(x) = \frac{1}{2} \ln\left| \frac{1+x}{1-x} \right| + C} \quad (\text{or } \text{arctanh}(x) + C \text{ for } |x| < 1) $$

(v) $y' = \frac{1}{x(1 - x)}$ ($x \neq 0, 1$):
 Decompose: $\frac{1}{x(1-x)} = \frac{1}{x} + \frac{1}{1-x}$. $$ y(x) = \int \left( \frac{1}{x} + \frac{1}{1-x} \right) dx = \ln|x| - \ln|1-x| + C = \mathbf{\ln\left| \frac{x}{1-x} \right| + C} $$

Phase 4: Final Result & Analysis
Boxed Solutions
  • (i) $y(x) = \frac{1}{3}e^{3x} - \frac{x^2}{2} + C$
  • (ii) $y(x) = \ln|x| + C$ on $x \in (-\infty, 0) \cup (0, \infty)$
  • (iii) $y(x) = \frac{1}{2}e^{x^2} + C$
  • (iv) $y(x) = \frac{1}{2}\ln\left|\frac{1+x}{1-x}\right| + C$
  • (v) $y(x) = \ln\left|\frac{x}{1-x}\right| + C$
Problem 2.2

Separable ODEs, Gaussian Integrals & Finite-Time Blow-Up

Separation of Variables • Error Integral • Singularity
Phase 1: Problem Statement & Hypotheses

Enunciado: Consider the equation: $$ \frac{dy}{dt} = e^{-t^2} y^2 $$ with initial condition $y(0) = y_0$.

(i) Solve the equation using separation of variables, expressing the solution in terms of $\int_0^t e^{-s^2} ds$.
(ii) Using $\int_0^\infty e^{-s^2} ds = \frac{\sqrt{\pi}}{2}$, show that if $y_0 < \frac{2}{\sqrt{\pi}}$, the solution exists for all $t > 0$ and find its limit as $t \to \infty$.
(iii) What happens if $y_0 > \frac{2}{\sqrt{\pi}}$?

Phase 2: Fundamental Formulation

The ODE is separable. For $y \neq 0$, separate variables $\frac{dy}{y^2} = e^{-t^2} dt$ and integrate across $[0, t]$. The denominator behavior dictates whether the solution exists globally or blows up in finite time.

Phase 3: Step-by-Step Derivation

Part (i): Integration:

$$ \int_{y_0}^{y(t)} \frac{du}{u^2} = \int_0^t e^{-s^2} ds \implies \left[ -\frac{1}{u} \right]_{y_0}^{y(t)} = \int_0^t e^{-s^2} ds $$ $$ -\frac{1}{y(t)} + \frac{1}{y_0} = \int_0^t e^{-s^2} ds \implies \frac{1}{y(t)} = \frac{1}{y_0} - \int_0^t e^{-s^2} ds = \frac{1 - y_0 \int_0^t e^{-s^2} ds}{y_0} $$ $$ \mathbf{y(t) = \frac{y_0}{1 - y_0 \int_0^t e^{-s^2} \, ds}} \tag{2.2.1} $$

Part (ii): Subcritical Regime ($y_0 < \frac{2}{\sqrt{\pi}}$):

Since $e^{-s^2} > 0$, the function $I(t) = \int_0^t e^{-s^2} ds$ is strictly monotonically increasing for $t \ge 0$, bounded by: $$ 0 \le \int_0^t e^{-s^2} ds < \int_0^\infty e^{-s^2} ds = \frac{\sqrt{\pi}}{2} $$ Therefore, if $y_0 < \frac{2}{\sqrt{\pi}}$, then $y_0 \int_0^t e^{-s^2} ds < y_0 \frac{\sqrt{\pi}}{2} < 1$ for all $t > 0$. The denominator never reaches zero! The solution exists globally $\forall t \in [0, \infty)$. Taking the limit as $t \to \infty$: $$ \lim_{t \to \infty} y(t) = \mathbf{\frac{y_0}{1 - y_0 \frac{\sqrt{\pi}}{2}}} $$

Part (iii): Supercritical Regime ($y_0 > \frac{2}{\sqrt{\pi}}$):

If $y_0 > \frac{2}{\sqrt{\pi}}$, then $\frac{1}{y_0} < \frac{\sqrt{\pi}}{2} = \int_0^\infty e^{-s^2} ds$. By the Intermediate Value Theorem, there exists a unique finite time $t^* \in (0, \infty)$ such that: $$ \int_0^{t^*} e^{-s^2} ds = \frac{1}{y_0} $$ As $t \to t^{*-}$, the denominator approaches $0^+$, causing a finite-time blow-up: $$ \lim_{t \to t^{*-}} y(t) = +\infty $$ The solution ceases to exist beyond $t^*$.

Phase 4: Final Result & Analysis
Boxed Result
$$ y(t) = \frac{y_0}{1 - y_0 \int_0^t e^{-s^2} ds} $$
  • $y_0 < \frac{2}{\sqrt{\pi}} \implies$ Global existence $\forall t \ge 0$, with $\lim_{t\to\infty} y(t) = \frac{y_0}{1 - y_0 \sqrt{\pi}/2}$.
  • $y_0 > \frac{2}{\sqrt{\pi}} \implies$ Finite-time blow-up at $t^*$ where $\int_0^{t^*} e^{-s^2} ds = 1/y_0$.
Problem 2.3

The Integrating Factor Method & Asymptotic Limits (8 Equations)

Linear 1st-Order ODEs • Integrating Factor • Steady State
Phase 1: Problem Statement & Hypotheses

Enunciado: Find the general solution of the following equations using an integrating factor:

(i) $y' + 2y = e^x$
(ii) $y' + y = e^{-x}$
(iii) $y' - y = e^x$
(iv) $y' + 2xy = x$
(v) $y' + y \cot x = 1$
(vi) $y' + y \tanh x = 1$
(vii) $x' + \frac{x}{t} = 1$
(viii) $x' + \left(a + \frac{1}{t}\right)x = b \quad (a > 0)$

For (viii), find the limit of the solution as $t \to \infty$.

Phase 2: Fundamental Formulation

Each equation has standard linear form $y' + p(x)y = q(x)$. The integrating factor is $\mu(x) = \exp\left(\int p(x) dx\right)$, transforming the ODE into $\frac{d}{dx}[\mu y] = \mu q(x)$, with solution $y = \frac{1}{\mu}[\int \mu q dx + C]$.

Phase 3: Step-by-Step Derivation

(i) $y' + 2y = e^x$:
$\mu(x) = e^{\int 2 dx} = e^{2x}$.
$\frac{d}{dx}[y e^{2x}] = e^{2x} e^x = e^{3x} \implies y e^{2x} = \frac{1}{3} e^{3x} + C \implies \mathbf{y(x) = \frac{1}{3} e^x + C e^{-2x}}$.

(ii) $y' + y = e^{-x}$:
$\mu(x) = e^{\int 1 dx} = e^x$.
$\frac{d}{dx}[y e^x] = e^x e^{-x} = 1 \implies y e^x = x + C \implies \mathbf{y(x) = (x + C)e^{-x}}$.

(iii) $y' - y = e^x$:
$\mu(x) = e^{\int (-1) dx} = e^{-x}$.
$\frac{d}{dx}[y e^{-x}] = e^{-x} e^x = 1 \implies y e^{-x} = x + C \implies \mathbf{y(x) = (x + C)e^x}$.

(iv) $y' + 2xy = x$:
$\mu(x) = e^{\int 2x dx} = e^{x^2}$.
$\frac{d}{dx}[y e^{x^2}] = x e^{x^2} \implies y e^{x^2} = \frac{1}{2} e^{x^2} + C \implies \mathbf{y(x) = \frac{1}{2} + C e^{-x^2}}$.

(v) $y' + y \cot x = 1$:
$\int \cot x dx = \int \frac{\cos x}{\sin x} dx = \ln|\sin x| \implies \mu(x) = e^{\ln|\sin x|} = \sin x$.
$\frac{d}{dx}[y \sin x] = \sin x \implies y \sin x = -\cos x + C \implies \mathbf{y(x) = -\cot x + C \csc x}$.

(vi) $y' + y \tanh x = 1$:
$\int \tanh x dx = \int \frac{\sinh x}{\cosh x} dx = \ln(\cosh x) \implies \mu(x) = \cosh x$.
$\frac{d}{dx}[y \cosh x] = \cosh x \implies y \cosh x = \sinh x + C \implies \mathbf{y(x) = \tanh x + C \text{sech}(x)}$.

(vii) $x' + \frac{x}{t} = 1$:
$\mu(t) = e^{\int \frac{1}{t} dt} = e^{\ln t} = t$.
$\frac{d}{dt}[x t] = t \implies x t = \frac{t^2}{2} + C \implies \mathbf{x(t) = \frac{t}{2} + \frac{C}{t}}$.

(viii) $x' + \left(a + \frac{1}{t}\right)x = b \quad (a > 0)$:
$\int \left(a + \frac{1}{t}\right) dt = at + \ln t \implies \mu(t) = e^{at + \ln t} = t e^{at}$.
$\frac{d}{dt}[x t e^{at}] = b t e^{at}$. Integrating by parts ($\int t e^{at} dt = \frac{t e^{at}}{a} - \frac{e^{at}}{a^2}$):
$$ x t e^{at} = b \left( \frac{t e^{at}}{a} - \frac{e^{at}}{a^2} \right) + C \implies \mathbf{x(t) = \frac{b}{a} - \frac{b}{a^2 t} + \frac{C}{t} e^{-at}} $$ Taking the limit as $t \to \infty$ with $a > 0$ (so $e^{-at} \to 0$ and $1/t \to 0$):
$$ \lim_{t \to \infty} x(t) = \frac{b}{a} - 0 + 0 = \mathbf{\frac{b}{a}} $$

Phase 4: Final Result & Analysis
Boxed Solutions Summary

(i) $y = \frac{1}{3}e^x + C e^{-2x}$  |  (ii) $y = (x+C)e^{-x}$  |  (iii) $y = (x+C)e^x$  |  (iv) $y = \frac{1}{2} + C e^{-x^2}$
(v) $y = -\cot x + C \csc x$  |  (vi) $y = \tanh x + C\text{sech}(x)$  |  (vii) $x = \frac{t}{2} + \frac{C}{t}$
(viii) $x(t) = \frac{b}{a} - \frac{b}{a^2 t} + \frac{C}{t}e^{-at}$, with $\mathbf{\lim_{t\to\infty} x(t) = \frac{b}{a}}$.

Problem 2.4

Exact Differential Equations & Potential Reconstruction (4 Equations)

Exact Differentials • Euler-Cauchy Test • Potential Surface
Phase 1: Problem Statement & Hypotheses

Enunciado: Show that the following equations are exact and find their general solutions:

  1. (i) $(2x + y) + (x + 2y)y' = 0$
  2. (ii) $(2xy + 1) + (x^2 + 4y)y' = 0$
  3. (iii) $(x^2 + y) + (x + e^y)y' = 0$
  4. (iv) $(3x^2 + 2xy) + (x^2 + y^3)y' = 0$
Phase 2: Fundamental Formulation

In form $M(x, y) dx + N(x, y) dy = 0$. Check exactness criterion $\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x}$. Then reconstruct $F(x, y)$ such that $\frac{\partial F}{\partial x} = M$ and $\frac{\partial F}{\partial y} = N$, with general solution $F(x, y) = C$.

Phase 3: Step-by-Step Derivation

(i) $(2x + y) dx + (x + 2y) dy = 0$:
$M = 2x + y \implies \frac{\partial M}{\partial y} = 1$. $N = x + 2y \implies \frac{\partial N}{\partial x} = 1$. Exact! ($\partial M/\partial y = \partial N/\partial x$).
$F(x, y) = \int (2x + y) dx = x^2 + xy + h(y)$.
$\frac{\partial F}{\partial y} = x + h'(y) = x + 2y \implies h'(y) = 2y \implies h(y) = y^2$.
General solution: $\mathbf{x^2 + xy + y^2 = C}$.

(ii) $(2xy + 1) dx + (x^2 + 4y) dy = 0$:
$M = 2xy + 1 \implies \frac{\partial M}{\partial y} = 2x$. $N = x^2 + 4y \implies \frac{\partial N}{\partial x} = 2x$. Exact!
$F(x, y) = \int (2xy + 1) dx = x^2 y + x + h(y)$.
$\frac{\partial F}{\partial y} = x^2 + h'(y) = x^2 + 4y \implies h'(y) = 4y \implies h(y) = 2y^2$.
General solution: $\mathbf{x^2 y + x + 2y^2 = C}$.

(iii) $(x^2 + y) dx + (x + e^y) dy = 0$:
$M = x^2 + y \implies \frac{\partial M}{\partial y} = 1$. $N = x + e^y \implies \frac{\partial N}{\partial x} = 1$. Exact!
$F(x, y) = \int (x^2 + y) dx = \frac{x^3}{3} + xy + h(y)$.
$\frac{\partial F}{\partial y} = x + h'(y) = x + e^y \implies h'(y) = e^y \implies h(y) = e^y$.
General solution: $\mathbf{\frac{x^3}{3} + xy + e^y = C}$.

(iv) $(3x^2 + 2xy) dx + (x^2 + y^3) dy = 0$:
$M = 3x^2 + 2xy \implies \frac{\partial M}{\partial y} = 2x$. $N = x^2 + y^3 \implies \frac{\partial N}{\partial x} = 2x$. Exact!
$F(x, y) = \int (3x^2 + 2xy) dx = x^3 + x^2 y + h(y)$.
$\frac{\partial F}{\partial y} = x^2 + h'(y) = x^2 + y^3 \implies h'(y) = y^3 \implies h(y) = \frac{y^4}{4}$.
General solution: $\mathbf{x^3 + x^2 y + \frac{y^4}{4} = C}$.

Phase 4: Final Result & Analysis
Boxed Potential Functions
  • (i) $x^2 + xy + y^2 = C$
  • (ii) $x^2 y + x + 2y^2 = C$
  • (iii) $\frac{x^3}{3} + xy + e^y = C$
  • (iv) $x^3 + x^2 y + \frac{y^4}{4} = C$
Problem 2.5

Special Integrating Factor for Non-Exact Equations

Non-Exact Form • Multiplier $\mu(x)=x$ • Potential Reconstruction
Phase 1: Problem Statement & Hypotheses

Enunciado: Show that the equation: $$ (3xy + y^2) + (x^2 + xy)y' = 0 $$ is not exact. Find an integrating factor $I(x)$ depending only on $x$, and use it to solve the equation.

Phase 2: Fundamental Formulation

$M = 3xy + y^2$, $N = x^2 + xy$. Test $\partial M/\partial y$ vs $\partial N/\partial x$. If unequal, compute $\phi(x) = \frac{M_y - N_x}{N}$. The integrating factor is $I(x) = \exp\left(\int \phi(x) dx\right)$.

Phase 3: Step-by-Step Derivation

Step 1: Check Exactness:

$$ \frac{\partial M}{\partial y} = \frac{\partial}{\partial y}(3xy + y^2) = 3x + 2y $$ $$ \frac{\partial N}{\partial x} = \frac{\partial}{\partial x}(x^2 + xy) = 2x + y $$ Since $3x + 2y \neq 2x + y$, the equation is not exact.

Step 2: Construct Integrating Factor $I(x)$:

$$ \phi(x) = \frac{\frac{\partial M}{\partial y} - \frac{\partial N}{\partial x}}{N} = \frac{(3x + 2y) - (2x + y)}{x^2 + xy} = \frac{x + y}{x(x + y)} = \frac{1}{x} $$ This depends strictly on $x$. Thus: $$ I(x) = \exp\left( \int \frac{1}{x} \, dx \right) = e^{\ln x} = \mathbf{x} $$

Step 3: Multiply and Solve the Exact Equation:

Multiply by $I(x) = x$: $$ (3x^2 y + x y^2) \, dx + (x^3 + x^2 y) \, dy = 0 $$ Verify exactness: $\frac{\partial}{\partial y}(3x^2 y + xy^2) = 3x^2 + 2xy$; $\frac{\partial}{\partial x}(x^3 + x^2 y) = 3x^2 + 2xy$. Exact!
Integrate $M_{\text{new}}$: $$ F(x, y) = \int (3x^2 y + x y^2) \, dx = x^3 y + \frac{1}{2} x^2 y^2 + h(y) $$ Differentiate with respect to $y$: $$ \frac{\partial F}{\partial y} = x^3 + x^2 y + h'(y) = x^3 + x^2 y \implies h'(y) = 0 \implies h(y) = 0 $$ $$ \mathbf{x^3 y + \frac{1}{2} x^2 y^2 = C} $$
Phase 4: Final Result & Analysis
Boxed Result
$$ I(x) = x, \quad x^3 y + \frac{1}{2} x^2 y^2 = C $$
Problem 2.6

Universal Exactness of Separated Differential Forms

Separated Forms • Cross-Derivative Proof • Applications
Phase 1: Problem Statement & Hypotheses

Enunciado: Show that any differential equation that can be written in the form: $$ f(x) + g(y) \frac{dy}{dx} = 0 $$ is exact, and use this to solve the following equations:

(i) $x^3 + y y' = 0$
(ii) $\frac{2}{x} - b + \left(\frac{1}{y} - a\right)y' = 0$

Phase 2: Fundamental Formulation

In differential form: $f(x) dx + g(y) dy = 0$. Here $M(x, y) = f(x)$ and $N(x, y) = g(y)$. We evaluate the cross partial derivatives $\frac{\partial M}{\partial y}$ and $\frac{\partial N}{\partial x}$.

Phase 3: Step-by-Step Derivation

General Proof:

$$ \frac{\partial M}{\partial y} = \frac{\partial}{\partial y}[f(x)] = 0 $$ $$ \frac{\partial N}{\partial x} = \frac{\partial}{\partial x}[g(y)] = 0 $$ Since $\frac{\partial M}{\partial y} = \frac{\partial N}{\partial x} = 0$ identically on $\mathbb{R}^2$, any separated equation is unconditionally exact. The potential function is $F(x, y) = \int f(x) dx + \int g(y) dy = C$.

Application (i): $x^3 dx + y dy = 0$:

$$ F(x, y) = \int x^3 dx + \int y dy = \frac{x^4}{4} + \frac{y^2}{2} = C \implies \mathbf{x^4 + 2y^2 = C_1} $$

Application (ii): $\left(\frac{2}{x} - b\right) dx + \left(\frac{1}{y} - a\right) dy = 0$:

$$ F(x, y) = \int \left(\frac{2}{x} - b\right) dx + \int \left(\frac{1}{y} - a\right) dy = 2\ln|x| - bx + \ln|y| - ay = C $$ $$ \ln(x^2 |y|) - (bx + ay) = C \implies \mathbf{x^2 y e^{-(bx + ay)} = C_1} $$
Phase 4: Final Result & Analysis
Boxed Result

Proof: $\frac{\partial f(x)}{\partial y} \equiv 0 \equiv \frac{\partial g(y)}{\partial x} \implies$ Always exact.
(i) $x^4 + 2y^2 = C_1$
(ii) $x^2 y e^{-(bx + ay)} = C_1$ (Lotka-Volterra type conservative invariant).

Problem 2.7

Nonlinear Change of Variables ($z = y^2$)

Substitution • Linearization • IVP
Phase 1: Problem Statement & Hypotheses

Enunciado: Show that the substitution $z = y^2$ transforms the differential equation: $$ y' = y + \frac{x}{y}, \quad y(0) = 1 $$ into a linear equation for $z(x)$. Solve this linear equation, and then find $y(x)$.

Phase 2: Fundamental Formulation

Multiply by $y$ to obtain $y y' - y^2 = x$. Substitute $z = y^2 \implies z' = 2y y' \implies y y' = \frac{1}{2}z'$. This yields a linear ODE in $z(x)$, solvable by integrating factor.

Phase 3: Step-by-Step Derivation

Multiply by $y$: $y \frac{dy}{dx} - y^2 = x$.
With $z = y^2 \implies \frac{dz}{dx} = 2y \frac{dy}{dx} \implies y \frac{dy}{dx} = \frac{1}{2} \frac{dz}{dx}$. Substituting: $$ \frac{1}{2} \frac{dz}{dx} - z = x \iff \mathbf{\frac{dz}{dx} - 2z = 2x} \tag{2.7.1} $$ Integrating factor for (2.7.1): $\mu(x) = e^{\int (-2) dx} = e^{-2x}$.
$$ \frac{d}{dx}[z e^{-2x}] = 2x e^{-2x} $$ Integrate by parts ($\int 2x e^{-2x} dx = -x e^{-2x} - \frac{1}{2} e^{-2x}$): $$ z e^{-2x} = -x e^{-2x} - \frac{1}{2} e^{-2x} + C \implies z(x) = C e^{2x} - x - \frac{1}{2} $$ Initial condition: $y(0) = 1 \implies z(0) = [y(0)]^2 = 1^2 = 1$: $$ 1 = C e^0 - 0 - \frac{1}{2} \implies C = \frac{3}{2} $$ Therefore: $$ z(x) = \frac{3}{2} e^{2x} - x - \frac{1}{2} $$ Since $y(0) = 1 > 0$, taking the positive square root $y = +\sqrt{z}$: $$ \mathbf{y(x) = \sqrt{\frac{3}{2} e^{2x} - x - \frac{1}{2}}} \tag{2.7.2} $$

Phase 4: Final Result & Analysis
Boxed Result
$$ z' - 2z = 2x, \quad y(x) = \sqrt{\frac{3}{2} e^{2x} - x - \frac{1}{2}} $$

Domain: Defined where $\frac{3}{2}e^{2x} - x - 1/2 > 0$, which holds globally on $\mathbb{R}$.

Problem 2.8

General Bernoulli Equation Reduction ($z = y^{1-\alpha}$)

Bernoulli Theorem • Linearizing Transformation • Degenerate Cases
Phase 1: Problem Statement & Hypotheses

Enunciado: Consider the Bernoulli equation: $$ \frac{dy}{dx} = a(x) y + b(x) y^\alpha $$ (i) What happens when $\alpha = 0$? What happens when $\alpha = 1$?
(ii) Show that the substitution $z = y^{1-\alpha}$ transforms the equation into a linear equation for $z(x)$.

Phase 2: Fundamental Formulation

Analyze $\alpha=0$ and $\alpha=1$ as degenerate linear cases. For $\alpha \neq 0, 1$, divide by $y^\alpha$ and apply the chain rule to $z = y^{1-\alpha}$.

Phase 3: Step-by-Step Derivation

Part (i): Degenerate Cases:

  • $\alpha = 0$: $y^0 = 1 \implies \frac{dy}{dx} - a(x)y = b(x)$. This is already a standard linear inhomogeneous 1st-order ODE.
  • $\alpha = 1$: $y^1 = y \implies \frac{dy}{dx} = [a(x) + b(x)]y \implies \frac{dy}{dx} - [a(x) + b(x)]y = 0$. This is a linear homogeneous 1st-order ODE (and separable).

Part (ii): General Linearizing Transformation for $\alpha \neq 0, 1$:

Divide equation by $y^\alpha$: $$ y^{-\alpha} \frac{dy}{dx} - a(x) y^{1-\alpha} = b(x) \tag{2.8.1} $$ Let $z(x) \equiv y(x)^{1-\alpha}$. Differentiating by the chain rule: $$ \frac{dz}{dx} = (1 - \alpha) y^{-\alpha} \frac{dy}{dx} \implies y^{-\alpha} \frac{dy}{dx} = \frac{1}{1 - \alpha} \frac{dz}{dx} $$ Substitute into (2.8.1): $$ \frac{1}{1 - \alpha} \frac{dz}{dx} - a(x) z = b(x) $$ Multiply by $(1 - \alpha) \neq 0$: $$ \mathbf{\frac{dz}{dx} - (1 - \alpha) a(x) z = (1 - \alpha) b(x)} \tag{2.8.2} $$ Equation (2.8.2) is strictly linear in $z(x)$! Once $z(x)$ is solved, $y(x) = [z(x)]^{1/(1-\alpha)}$.

Phase 4: Final Result & Analysis
Boxed Result
$$ \frac{dz}{dx} - (1 - \alpha) a(x) z = (1 - \alpha) b(x) $$
Problem 2.9

Solution Uniqueness & Lipschitz Analysis at $x = 0$ (5 Cases)

Picard-Lindelöf • Lipschitz Test • Derivative Singularity
Phase 1: Problem Statement & Hypotheses

Enunciado: For which of the following equations does the existence and uniqueness theorem guarantee that the solution of $\frac{dx}{dt} = f(x)$ with $x(0) = 0$ is unique?

(i) $f(x) = x(1 - x^2)$
(ii) $f(x) = x^{1/3}$
(iii) $f(x) = x^3$
(iv) $f(x) = x^{1/2}(1 + x)^2$
(v) $f(x) = (1 + x)^{3/2}$
Phase 2: Fundamental Formulation

By Picard-Lindelöf, if $f(x)$ is $C^1$ in a neighborhood of $x = 0$ (i.e. $|f'(0)| < \infty$), $f$ is locally Lipschitz, guaranteeing a unique solution. If $f'(x) \to \infty$ as $x \to 0$, the Lipschitz condition fails, permitting branching non-uniqueness.

Phase 3: Step-by-Step Derivation

(i) $f(x) = x(1 - x^2) = x - x^3$:
$f'(x) = 1 - 3x^2 \implies f'(0) = 1 < \infty$. $f$ is smooth and locally Lipschitz. Unique! (The unique solution is $x(t) \equiv 0$).

(ii) $f(x) = x^{1/3}$:
$f'(x) = \frac{1}{3} x^{-2/3} = \frac{1}{3 x^{2/3}}$. As $x \to 0$, $f'(x) \to +\infty$. Not Lipschitz at $0$. Non-unique! (Admits $x(t) \equiv 0$ and $x(t) = \pm (2t/3)^{3/2}$).

(iii) $f(x) = x^3$:
$f'(x) = 3x^2 \implies f'(0) = 0 < \infty$. Continuously differentiable and locally Lipschitz. Unique! ($x(t) \equiv 0$).

(iv) $f(x) = x^{1/2}(1 + x)^2$:
$f'(x) = \frac{1}{2\sqrt{x}}(1+x)^2 + 2\sqrt{x}(1+x)$. As $x \to 0^+$, $f'(x) \sim \frac{1}{2\sqrt{x}} \to +\infty$. Not Lipschitz. Non-unique!

(v) $f(x) = (1 + x)^{3/2}$:
At $x = 0$, $f(0) = 1$. The derivative is $f'(x) = \frac{3}{2}(1+x)^{1/2} \implies f'(0) = \frac{3}{2} < \infty$. Continuously differentiable and locally Lipschitz. Unique!

Phase 4: Final Result & Analysis
Boxed Verdict
  • Unique solutions guaranteed: (i), (iii), and (v).
  • Uniqueness NOT guaranteed (Lipschitz failure): (ii) and (iv).
Problem 2.10

Uniqueness via Integrating Transformation (Without Picard)

Energy Transform • Linear Homogeneous ODE • Zero Trivial Solution
Phase 1: Problem Statement & Hypotheses

Enunciado: Show that if $y(t)$ satisfies: $$ \frac{dy}{dt} + p(t) y = 0, \quad y(t_0) = 0 $$ then $z(t) = y(t) \exp\left(\int_{t_0}^t p(s) ds\right)$ satisfies $\frac{dz}{dt} = 0$, and use this to deduce that the only solution of the initial value problem is $y(t) = 0$ for all $t$. (This proves uniqueness for linear first-order equations without using the Picard-Lindelöf Theorem.)

Phase 2: Fundamental Formulation

Define the transformed variable $z(t) = y(t) \mu(t)$, where $\mu(t) = \exp\left(\int_{t_0}^t p(s)ds\right) > 0$. Differentiate $z(t)$ using the product rule and Fundamental Theorem of Calculus.

Phase 3: Step-by-Step Derivation

Compute the time derivative of $\mu(t)$: $$ \frac{d\mu}{dt} = \frac{d}{dt}\left[\exp\left(\int_{t_0}^t p(s) ds\right)\right] = p(t) \exp\left(\int_{t_0}^t p(s) ds\right) = p(t) \mu(t) $$ Differentiating $z(t) = y(t) \mu(t)$ using the product rule: $$ \frac{dz}{dt} = \frac{dy}{dt} \mu(t) + y(t) \frac{d\mu}{dt} = \frac{dy}{dt} \mu(t) + y(t) p(t) \mu(t) = \mu(t) \left[ \frac{dy}{dt} + p(t) y \right] $$ Since $y(t)$ satisfies $\frac{dy}{dt} + p(t)y = 0$: $$ \mathbf{\frac{dz}{dt} = \mu(t) \cdot 0 = 0} \quad \forall t \tag{2.10.1} $$ Integrating $\frac{dz}{dt} = 0$ implies that $z(t)$ is constant: $z(t) \equiv C$.
Evaluate at $t = t_0$: $$ C = z(t_0) = y(t_0) \mu(t_0) = 0 \cdot e^0 = 0 $$ Therefore: $$ z(t) \equiv 0 \implies y(t) \exp\left(\int_{t_0}^t p(s) ds\right) = 0 $$ Since the exponential function is strictly positive ($\exp(\dots) > 0$): $$ \mathbf{y(t) \equiv 0} \quad \forall t \tag{2.10.2} $$

Phase 4: Final Result & Analysis
Boxed Result
$$ \frac{dz}{dt} \equiv 0 \implies z(t) = z(t_0) = 0 \implies y(t) \equiv 0 \quad \forall t $$

Significance: Provides an analytical, constructive proof of uniqueness for linear ODEs independent of metric fixed-point theorems.

Problem 2.11

Invariance of Solution Ratios in Linear Homogeneous ODEs

Quotient Rule • Linear Independence • 1D Subspace
Phase 1: Problem Statement & Hypotheses

Enunciado: Show that if $y_1(t)$ and $y_2(t)$ are both solutions of: $$ \frac{dy}{dt} + p(t) y = 0 $$ and $y_2(t) \neq 0$ for all $t$, then $\frac{d}{dt}\left(\frac{y_1}{y_2}\right) = 0$. Deduce that every solution of the equation is a constant multiple of $y_2(t)$.

Phase 2: Fundamental Formulation

Apply the quotient rule to $w(t) \equiv \frac{y_1(t)}{y_2(t)}$, using the differential relations $y_1' = -p(t)y_1$ and $y_2' = -p(t)y_2$.

Phase 3: Step-by-Step Derivation

Differentiating by the quotient rule: $$ \frac{d}{dt}\left( \frac{y_1}{y_2} \right) = \frac{y_1' y_2 - y_1 y_2'}{y_2^2} $$ Substitute $y_1' = -p(t)y_1$ and $y_2' = -p(t)y_2$: $$ \frac{d}{dt}\left( \frac{y_1}{y_2} \right) = \frac{[-p(t) y_1] y_2 - y_1 [-p(t) y_2]}{y_2^2} = \frac{-p(t) y_1 y_2 + p(t) y_1 y_2}{y_2^2} = \mathbf{0} $$ Since the derivative is zero for all $t$: $$ \frac{y_1(t)}{y_2(t)} = C \implies \mathbf{y_1(t) = C y_2(t)} \tag{2.11.1} $$ where $C = \frac{y_1(t_0)}{y_2(t_0)}$.

Phase 4: Final Result & Linear Algebra Connection
Boxed Result
$$ \frac{d}{dt}\left(\frac{y_1}{y_2}\right) = 0 \implies y_1(t) = C y_2(t) $$

Linear Algebra Interpretation: The solution space of a 1st-order linear homogeneous ODE is a 1-dimensional vector space spanned by any single non-zero solution $y_2(t)$.

Problem 2.12

Trajectory Crossing and Uniqueness Bounds (No-Crossing Theorem)

No-Crossing Theorem • Invariant Corridors • Barrier Solutions
Phase 1: Problem Statement & Hypotheses

Enunciado: (i) Show that the solution of $\frac{dy}{dt} = (y + 2)(y - 1)e^t$ with $y(0) = 0$ satisfies $y(t) > -2$ for all $t \in \mathbb{R}$.
(ii) Suppose that $y_1(t) = -t - 1$ and $y_2(t) = t^2 + 1$ are both solutions of $y' = f(y, t)$, where $f$ and $\frac{\partial f}{\partial y}$ are continuous on $\mathbb{R}^2$. What can you say about the solution with $y(0) = 0$?

Phase 2: Fundamental Formulation

The No-Crossing Theorem dictates that because $f(y, t)$ and $\frac{\partial f}{\partial y}$ are continuous on $\mathbb{R}^2$, distinct solutions cannot intersect or touch in the $(t, y)$ plane. Hence, any known solution serves as an impassable boundary barrier.

Phase 3: Step-by-Step Derivation

Part (i):
Notice that $y^*(t) \equiv -2$ is an equilibrium solution: $(-2 + 2)(-2 - 1)e^t = 0 \cdot (-3)e^t = 0 = \frac{d(-2)}{dt}$.
Likewise, $y^{**}(t) \equiv 1$ is an equilibrium solution.
The initial condition is $y(0) = 0$, which satisfies $-2 < y(0) = 0 < 1$.
Since $f(y, t) = (y+2)(y-1)e^t$ and $\frac{\partial f}{\partial y} = (2y+1)e^t$ are continuous everywhere on $\mathbb{R}^2$, the Picard-Lindelöf theorem guarantees uniqueness.
Therefore, $y(t)$ can never cross the line $y = -2$. Since $y(0) > -2$, by continuity: $$ \mathbf{y(t) > -2 \quad \forall t \in \mathbb{R}} \tag{2.12.1} $$ (In fact, $-2 < y(t) < 1$ for all $t$).

Part (ii):
We are given two solutions $y_1(t) = -t - 1$ and $y_2(t) = t^2 + 1$.
Evaluate them at the initial time $t = 0$: $$ y_1(0) = -0 - 1 = -1 $$ $$ y_2(0) = 0^2 + 1 = 1 $$ The initial state $y(0) = 0$ lies strictly between them: $$ y_1(0) = -1 < y(0) = 0 < y_2(0) = 1 $$ By the No-Crossing Theorem, the solution curve $y(t)$ can never intersect $y_1(t)$ from below nor $y_2(t)$ from above.
Consequently, $y(t)$ is trapped for all $t \in \mathbb{R}$ within the invariant parabolic corridor: $$ \mathbf{-t - 1 < y(t) < t^2 + 1 \quad \forall t \in \mathbb{R}} \tag{2.12.2} $$

Phase 4: Final Result & Analysis
Boxed Bounds
  • (i) $y(t) > -2$ (and $-2 < y(t) < 1$) for all $t$.
  • (ii) $-t - 1 < y(t) < t^2 + 1$ for all $t \in \mathbb{R}$.
Problem 2.13

Multi-Equilibria Autonomous Phase Line Dynamics

Phase Line • Equilibria Barriers • Asymptotic Limits
Phase 1: Problem Statement & Hypotheses

Enunciado: Show that $y = 0$, $y = 2$, and $y = 3$ are all solutions of: $$ \frac{dy}{dt} = y(y - 2)(y - 3) $$ Deduce what happens as $t \to \infty$ to the solutions that have:
(i) $y(0) = -1$; (ii) $y(0) = 1$; (iii) $y(0) = 2.5$; (iv) $y(0) = 4$.

Phase 2: Fundamental Formulation

For an autonomous equation $\dot{y} = f(y)$, stationary points $f(y^*)=0$ act as constant solutions and invariant barriers. The sign of $f(y)$ dictates the direction of monotonic motion along the phase line.

Phase 3: Step-by-Step Derivation

Verification of Constant Solutions:
$f(0) = 0(0-2)(0-3) = 0$; $f(2) = 2(0)(2-3) = 0$; $f(3) = 3(3-2)(0) = 0$. Since $\frac{d}{dt}(\text{const}) = 0$, $y=0, 2, 3$ are exact solutions.

Phase Line Sign Analysis:

  • $y \in (3, \infty)$: $f(y) = (+)(+)(+) > 0 \implies y'(t) > 0$. Trajectories increase monotonically toward $+\infty$.
  • $y \in (2, 3)$: $f(y) = (+)(+)(-) < 0 \implies y'(t) < 0$. Trajectories decrease monotonically toward $y = 2$.
  • $y \in (0, 2)$: $f(y) = (+)(-)(-) > 0 \implies y'(t) > 0$. Trajectories increase monotonically toward $y = 2$.
  • $y \in (-\infty, 0)$: $f(y) = (-)(-)(-) < 0 \implies y'(t) < 0$. Trajectories decrease monotonically toward $-\infty$.

Evaluation of the 4 Initial Conditions:

  1. (i) $y(0) = -1 \in (-\infty, 0)$: $y' < 0 \implies y(t)$ decreases monotonically: $\mathbf{\lim_{t\to\infty} y(t) = -\infty}$.
  2. (ii) $y(0) = 1 \in (0, 2)$: $y' > 0 \implies y(t)$ increases monotonically toward equilibrium 2: $\mathbf{\lim_{t\to\infty} y(t) = 2}$.
  3. (iii) $y(0) = 2.5 \in (2, 3)$: $y' < 0 \implies y(t)$ decreases monotonically toward equilibrium 2: $\mathbf{\lim_{t\to\infty} y(t) = 2}$.
  4. (iv) $y(0) = 4 \in (3, \infty)$: $y' > 0 \implies y(t)$ increases monotonically without bound: $\mathbf{\lim_{t\to\infty} y(t) = +\infty}$.
Phase 4: Final Result & Analysis
Boxed Asymptotic Limits
  • (i) $y(0) = -1 \implies \lim_{t\to\infty} y(t) = -\infty$
  • (ii) $y(0) = 1 \implies \lim_{t\to\infty} y(t) = 2$
  • (iii) $y(0) = 2.5 \implies \lim_{t\to\infty} y(t) = 2$
  • (iv) $y(0) = 4 \implies \lim_{t\to\infty} y(t) = +\infty$

Stability Summary: $y^* = 0$ is an unstable source; $y^* = 2$ is an asymptotically stable attractor; $y^* = 3$ is an unstable source.

Problem 2.14

Non-Lipschitz Branching Pathology in Picard's Theorem

Failure of Uniqueness • Infinite Derivative • Non-Lipschitz
Phase 1: Problem Statement & Hypotheses

Enunciado: Show that $y_1(t) = 0$ and $y_2(t) = t^3$ are both solutions of: $$ \frac{dy}{dt} = 3 y^{2/3}, \quad y(0) = 0 $$ Explain why this does not contradict the existence and uniqueness theorem.

Phase 2: Fundamental Formulation

Verify both solutions by direct substitution. Test whether the vector field $f(t, y) = 3y^{2/3}$ satisfies the Lipschitz condition at $y = 0$ by evaluating the partial derivative $\frac{\partial f}{\partial y}$.

Phase 3: Step-by-Step Derivation

Step 1: Verification of $y_1(t) = 0$:
$y_1(0) = 0$. $\frac{dy_1}{dt} = 0$. RHS: $3(y_1)^{2/3} = 3(0)^{2/3} = 0$. LHS = RHS = 0. Valid!

Step 2: Verification of $y_2(t) = t^3$:
$y_2(0) = 0^3 = 0$. $\frac{dy_2}{dt} = \frac{d}{dt}(t^3) = 3t^2$.
RHS: $3(y_2)^{2/3} = 3(t^3)^{2/3} = 3(t^{3 \cdot \frac{2}{3}}) = 3t^2$. LHS = RHS = $3t^2$. Valid!

Step 3: Verification of Non-Contradiction with Picard-Lindelöf:
Picard's theorem requires that $f(t, y)$ is locally Lipschitz in $y$. For $f(y) = 3y^{2/3}$: $$ \frac{\partial f}{\partial y} = 3 \cdot \frac{2}{3} y^{-1/3} = \frac{2}{y^{1/3}} $$ As $y \to 0$: $$ \lim_{y \to 0} \left| \frac{\partial f}{\partial y} \right| = \lim_{y \to 0} \frac{2}{|y|^{1/3}} = +\infty $$ The partial derivative is unbounded in any neighborhood of $y = 0$. The Lipschitz condition is strictly violated. Since the hypothesis of the theorem is not satisfied, the theorem makes no guarantee of uniqueness.

Phase 4: Final Result & Analysis
Boxed Conclusion

Both $y_1(t)=0$ and $y_2(t)=t^3$ are valid solutions with $y(0)=0$. This does not contradict Picard-Lindelöf because $\frac{\partial f}{\partial y}(0) = \infty$, violating the Lipschitz condition.

Problem 2.15

Singular ODE and Domain of Definition

Domain Singularity • Undefined Vector Field • Family of Parabolas
Phase 1: Problem Statement & Hypotheses

Enunciado: Find the general solution of: $$ \frac{dy}{dt} = \frac{2y + 1}{t} $$ and show that there are an infinite number of solutions that satisfy $y(0) = -\frac{1}{2}$. Does this contradict the existence and uniqueness theorem?

Phase 2: Fundamental Formulation

Separate variables for $t \neq 0$ and $2y + 1 \neq 0$. Check the definition of $f(t, y) = \frac{2y+1}{t}$ at $t = 0$.

Phase 3: Step-by-Step Derivation

Step 1: Separation of Variables for $t \neq 0$:

$$ \frac{1}{2y + 1} \, dy = \frac{1}{t} \, dt $$ $$ \int \frac{1}{2y + 1} \, dy = \int \frac{1}{t} \, dt \implies \frac{1}{2} \ln|2y + 1| = \ln|t| + C_0 $$ Multiply by 2: $$ \ln|2y + 1| = 2\ln|t| + 2C_0 = \ln(t^2) + \ln C_1 \implies |2y + 1| = C_1 t^2 $$ Removing absolute values: $$ 2y + 1 = C t^2 \implies \mathbf{y(t) = -\frac{1}{2} + C t^2} \tag{2.15.1} $$ where $C \in \mathbb{R}$ is an arbitrary constant.

Step 2: Checking $y(0) = -1/2$:

$$ y(0) = -\frac{1}{2} + C(0)^2 = -\frac{1}{2} \quad \forall C \in \mathbb{R} $$ Every single parabola in the infinite family passes through $(0, -1/2)$!

Step 3: Picard-Lindelöf Compatibility:

The vector field is $f(t, y) = \frac{2y + 1}{t}$. At $t = 0$, $f(t, y)$ has a division by zero: it is undefined (discontinuous). Picard-Lindelöf requires that $f(t, y)$ is continuous on an open domain containing $(t_0, y_0)$. Since $(0, -1/2)$ is not in the domain of $f$, the theorem does not apply. No contradiction exists!

Phase 4: Final Result & Analysis
Boxed Result
$$ y(t) = -\frac{1}{2} + C t^2 \quad (C \in \mathbb{R}) $$

Does not contradict Picard-Lindelöf because $f(t, y) = \frac{2y+1}{t}$ is not defined at $t=0$.

Problem 2.16

Pitchfork Phase Line & Stability Regimes

Supercritical Pitchfork • Stability Derivative • Aeroelastic Model
Phase 1: Problem Statement & Hypotheses

Enunciado: Find the stationary points of: $$ \frac{dx}{dt} = x(\kappa^2 - x^2) $$ where $\kappa > 0$. By sketching the graph of $f(x) = x(\kappa^2 - x^2)$, determine their stability. What happens to the solution with $x(0) = x_0$ as $t \to \infty$ for different values of $x_0$?

Phase 2: Fundamental Formulation

Stationary points satisfy $f(x) = 0$. Stability is evaluated by the sign of $f'(x^*)$: if $f'(x^*) < 0$, it is asymptotically stable; if $f'(x^*) > 0$, it is unstable.

Phase 3: Step-by-Step Derivation

Step 1: Finding Stationary Points:

$$ f(x) = x(\kappa^2 - x^2) = x(\kappa - x)(\kappa + x) = 0 $$ Since $\kappa > 0$, there are 3 distinct equilibria: $$ \mathbf{x_1^* = -\kappa, \quad x_2^* = 0, \quad x_3^* = +\kappa} $$

Step 2: Stability Analysis via $f'(x)$:

$$ f(x) = \kappa^2 x - x^3 \implies f'(x) = \kappa^2 - 3x^2 $$
  • At $x_2^* = 0$: $f'(0) = \kappa^2 > 0 \implies$ Unstable Node (Repellor).
  • At $x_1^* = -\kappa$: $f'(-\kappa) = \kappa^2 - 3(-\kappa)^2 = -2\kappa^2 < 0 \implies$ Asymptotically Stable Attractor (Sink).
  • At $x_3^* = +\kappa$: $f'(+\kappa) = \kappa^2 - 3(\kappa)^2 = -2\kappa^2 < 0 \implies$ Asymptotically Stable Attractor (Sink).

Step 3: Global Asymptotic Regimes ($t \to \infty$):

  • If $x_0 > 0$: Trajectory is attracted to $+\kappa$: $\mathbf{\lim_{t\to\infty} x(t) = +\kappa}$.
  • If $x_0 = 0$: Stays on equilibrium forever: $\mathbf{x(t) \equiv 0}$.
  • If $x_0 < 0$: Trajectory is attracted to $-\kappa$: $\mathbf{\lim_{t\to\infty} x(t) = -\kappa}$.
Phase 4: Final Result & Pitchfork Bifurcation
Boxed Result
$$ x^* = 0 \text{ (Unstable)}, \quad x^* = \pm\kappa \text{ (Asymptotically Stable)} $$ $$ \lim_{t\to\infty} x(t) = \begin{cases} +\kappa & \text{if } x_0 > 0 \\ 0 & \text{if } x_0 = 0 \\ -\kappa & \text{if } x_0 < 0 \end{cases} $$

Aerospace Connection: Canonical equation of a supercritical pitchfork bifurcation, modeling wing panel post-buckling deflection and aircraft spin-trim states.

Problem 2.17

Direct Difference Method for Uniqueness

Energy Function • Difference Equation • Direct Proof
Phase 1: Problem Statement & Hypotheses

Enunciado: Show that $y_1(t) = t - 1$ is a solution of: $$ \frac{dy}{dt} = -y + t, \quad y(0) = -1 $$ Now suppose that $y_2(t)$ is another solution. Write down a differential equation for $w(t) = y_1(t) - y_2(t)$. Show that $w(t) = 0$ for all $t \ge 0$, and deduce that $y_1(t)$ is the only solution.

Phase 2: Fundamental Formulation

Verify $y_1(t)$ by substitution. Construct $w(t) = y_1(t) - y_2(t)$, which satisfies $w(0) = y_1(0) - y_2(0) = -1 - (-1) = 0$. Use the difference equation $w' = -w$ to prove $w(t) \equiv 0$.

Phase 3: Step-by-Step Derivation

Step 1: Inspection Verification of $y_1(t) = t - 1$:
$y_1(0) = 0 - 1 = -1$ (satisfies IC).
$\frac{dy_1}{dt} = \frac{d}{dt}(t - 1) = 1$.
RHS: $-y_1 + t = -(t - 1) + t = -t + 1 + t = 1$. LHS = RHS = 1. Valid!

Step 2: Differential Equation for the Difference $w(t) \equiv y_1(t) - y_2(t)$:
Since both $y_1$ and $y_2$ satisfy the differential equation: $$ \frac{dy_1}{dt} = -y_1 + t $$ $$ \frac{dy_2}{dt} = -y_2 + t $$ Subtracting the second equation from the first: $$ \frac{dw}{dt} = \frac{dy_1}{dt} - \frac{dy_2}{dt} = (-y_1 + t) - (-y_2 + t) = -(y_1 - y_2) = -w(t) $$ $$ \mathbf{\frac{dw}{dt} + w(t) = 0} \tag{2.17.1} $$ The initial condition is: $$ w(0) = y_1(0) - y_2(0) = -1 - (-1) = 0 $$

Step 3: Proving $w(t) \equiv 0$:
Equation (2.17.1) is solved using integrating factor $e^t$: $$ \frac{d}{dt}[w(t) e^t] = 0 \implies w(t) e^t = C \implies w(t) = C e^{-t} $$ Using $w(0) = 0$: $$ 0 = C e^0 \implies C = 0 \implies \mathbf{w(t) \equiv 0 \quad \forall t \ge 0} $$ Alternatively, via energy function $E(t) = \frac{1}{2}w(t)^2$: $$ \frac{dE}{dt} = w \dot{w} = w(-w) = -w^2 = -2E \le 0 \implies 0 \le E(t) \le E(0) e^{-2t} = 0 \implies E(t) \equiv 0 $$ Since $w(t) = y_1(t) - y_2(t) \equiv 0$, we have: $$ \mathbf{y_2(t) \equiv y_1(t) = t - 1} $$ proving that $y_1(t) = t - 1$ is the unique solution of the initial value problem.

Phase 4: Final Result & Methodological Significance
Boxed Result
$$ w' + w = 0, \; w(0) = 0 \implies w(t) \equiv 0 \implies y(t) = t - 1 \text{ is the unique solution} $$

Lyapunov / Energy Method: Proves uniqueness by showing that perturbations in the solution difference contract exponentially ($\dot{E} = -2E$).
