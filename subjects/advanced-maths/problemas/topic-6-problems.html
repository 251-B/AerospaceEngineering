Exercise 1

Sturm-Liouville Eigenvalues under Four Boundary Conditions

Original statement · probls_ch6_2627.pdf
Eigenvalues for four boundary conditions
Statement

Determine the eigenvalues and eigenfunctions of the Sturm-Liouville problems obtained for the equation $\phi''(x) + \lambda\phi(x) = 0$ with $0 < x < 1$ and each of the following boundary conditions:

  1. $\phi(0) = \phi(1) = 0$;
  2. $\phi(0) = \phi'(1) = 0$;
  3. $\phi'(0) = \phi'(1) = 0$;
  4. $\phi(0) = \phi'(1) + h\,\phi(1) = 0$, with $h > 0$.
Formulation and Sturm-Liouville Structure

The equation is already in self-adjoint form with $p(x) = 1$, $\sigma(x) = 1$, $q(x) = 0$, because $[1\cdot\phi']' + [\lambda\cdot 1 + 0]\phi = \phi'' + \lambda\phi$. Method: Notes09-12-Nov.pdf (Sturm-Liouville section; page to be confirmed); Haberman, Sec. 5.3.

General solution in each sign case

The characteristic equation $r^2 + \lambda = 0$ gives $r = \pm\sqrt{-\lambda}$, so the sign of $\lambda$ fixes the type of solution. Since no sign is known in advance, all three cases are tested in every part.

CaseWriteGeneral solutionDerivative
$\lambda < 0$$\lambda = -\mu^2,\ \mu > 0$$\phi = A\cosh\mu x + B\sinh\mu x$$\phi' = \mu(A\sinh\mu x + B\cosh\mu x)$
$\lambda = 0$$\phi = A + Bx$$\phi' = B$
$\lambda > 0$$\lambda = \mu^2,\ \mu > 0$$\phi = A\cos\mu x + B\sin\mu x$$\phi' = \mu(-A\sin\mu x + B\cos\mu x)$

Values used repeatedly: $\cosh\mu x > 0$ for all $x$, and $\sinh\mu x > 0$ for $\mu x > 0$. Derivative rule for $\cos$: chain rule $\frac{d}{dx}\cos(\mu x) = -\mu\sin(\mu x)$.

Eigenvalue Cases (Negative, Zero, Positive)
(i) $\phi(0) = \phi(1) = 0$
  • $\lambda < 0$: $\phi(0) = A = 0$. Then $\phi(1) = B\sinh\mu = 0$ with $\sinh\mu > 0$, so $B = 0$. Only the trivial solution.
  • $\lambda = 0$: $\phi(0) = A = 0$, $\phi(1) = A + B = B = 0$. Trivial.
  • $\lambda > 0$: $\phi(0) = A = 0$. Then $\phi(1) = B\sin\mu = 0$. A non-trivial solution needs $B \ne 0$, hence $\sin\mu = 0$, so $\mu = n\pi$ ($n = 1, 2, \dots$; $\mu > 0$ excludes $n = 0$ and negative $n$ gives the same functions up to sign).
(i)

$\lambda_n = n^2\pi^2,\quad \phi_n(x) = \sin(n\pi x),\quad n = 1, 2, 3, \dots$

(ii) $\phi(0) = \phi'(1) = 0$
  • $\lambda < 0$: $\phi(0) = A = 0$, so $\phi = B\sinh\mu x$ and $\phi'(1) = B\mu\cosh\mu = 0$. Since $\mu\cosh\mu > 0$, $B = 0$. Trivial.
  • $\lambda = 0$: $A = 0$, and $\phi'(1) = B = 0$. Trivial.
  • $\lambda > 0$: $A = 0$, $\phi = B\sin\mu x$, $\phi'(1) = B\mu\cos\mu = 0$. With $B \ne 0$ and $\mu > 0$: $\cos\mu = 0$, so $\mu = \frac{(2n-1)\pi}{2}$.
(ii)

$\lambda_n = \left(\dfrac{(2n-1)\pi}{2}\right)^2,\quad \phi_n(x) = \sin\!\left(\dfrac{(2n-1)\pi x}{2}\right),\quad n = 1, 2, 3, \dots$

(iii) $\phi'(0) = \phi'(1) = 0$
  • $\lambda < 0$: $\phi'(0) = \mu B = 0$ gives $B = 0$. Then $\phi'(1) = \mu A\sinh\mu = 0$ with $\sinh\mu > 0$ gives $A = 0$. Trivial.
  • $\lambda = 0$: $\phi' = B$, so $\phi'(0) = \phi'(1) = B = 0$. This leaves $\phi = A$ with $A$ arbitrary, which is non-trivial.
  • $\lambda > 0$: $\phi'(0) = \mu B = 0$ gives $B = 0$. Then $\phi'(1) = -\mu A\sin\mu = 0$ gives $\sin\mu = 0$, so $\mu = n\pi$, $n \ge 1$.
$\lambda = 0$ is an eigenvalue here

Unlike (i), (ii) and (iv), the Neumann conditions admit the constant function. So $\lambda_0 = 0$, $\phi_0(x) = 1$. Dropping this case would lose the constant mode of every Fourier cosine series. Check: $\phi_0'' + 0\cdot\phi_0 = 0$ and $\phi_0'(0) = \phi_0'(1) = 0$.

(iii)

$\lambda_0 = 0,\ \phi_0(x) = 1$; and $\lambda_n = n^2\pi^2,\ \phi_n(x) = \cos(n\pi x)$, $n = 1, 2, 3, \dots$ (the formula $\cos(n\pi x)$ with $n = 0$ reproduces $\phi_0$).

(iv) $\phi(0) = 0$ and $\phi'(1) + h\,\phi(1) = 0$, with $h > 0$
  • $\lambda < 0$: $A = 0$, $\phi = B\sinh\mu x$. The second condition is $B(\mu\cosh\mu + h\sinh\mu) = 0$. Since $\mu > 0$, $h > 0$, $\cosh\mu > 0$, $\sinh\mu > 0$, the bracket is strictly positive, so $B = 0$. Trivial.
  • $\lambda = 0$: $A = 0$, $\phi = Bx$, $\phi' = B$. Then $\phi'(1) + h\phi(1) = B + hB = B(1+h) = 0$ and $1 + h > 0$, so $B = 0$. Trivial.
  • $\lambda > 0$: $A = 0$, $\phi = B\sin\mu x$, and

$$ \phi'(1) + h\phi(1) = B\left(\mu\cos\mu + h\sin\mu\right) = 0. $$

If $\cos\mu = 0$ then $\sin\mu = \pm 1$ and the bracket equals $\pm h \ne 0$, so $\cos\mu \ne 0$ at any eigenvalue. Dividing by $h\cos\mu$:

$$ \tan\mu = -\frac{\mu}{h}. $$

Graphical location of the roots

Plot $y = \tan\mu$ and $y = -\mu/h$ for $\mu > 0$.

  • On $(0, \pi/2)$ and, in general, on $(n\pi, (2n+1)\pi/2)$: $\tan\mu > 0$ while $-\mu/h < 0$, so there is no intersection.
  • On $\left(\frac{(2n-1)\pi}{2}, n\pi\right)$: $\tan\mu$ rises continuously from $-\infty$ to $0$ while $-\mu/h$ is finite and negative. Define $f(\mu) = \tan\mu + \mu/h$. Then $f \to -\infty$ at the left end, $f(n\pi) = n\pi/h > 0$ at the right end, so a root exists, and it is unique because $f'(\mu) = \sec^2\mu + 1/h > 0$.

Hence exactly one root $\mu_n$ lies in each interval $\left(\frac{(2n-1)\pi}{2}, n\pi\right)$, $n = 1, 2, \dots$ As $n \to \infty$, $-\mu_n/h \to -\infty$, so $\mu_n \to \frac{(2n-1)\pi}{2}$ from above.

Intersections of $y = \tan\mu$ and $y = -\mu/h$: one root $\mu_n$ in each interval $((2n-1)\pi/2,\ n\pi)$.

(iv)

$\lambda_n = \mu_n^2$ with $\mu_n$ the unique root of $\tan\mu = -\mu/h$ in $\left(\frac{(2n-1)\pi}{2}, n\pi\right)$, and $\phi_n(x) = \sin(\mu_n x)$, $n = 1, 2, 3, \dots$. No eigenvalue satisfies $\lambda \le 0$ when $h > 0$.

Eigenfunctions and Checks
  • Limiting cases in (iv): dividing the condition $\mu\cos\mu + h\sin\mu = 0$ by $h$ and letting $h \to \infty$ gives $\sin\mu = 0$, so $\mu_n \to n\pi$ (the condition becomes $\phi(1) = 0$, recovering (i)). Letting $h \to 0^+$ gives $\mu\cos\mu = 0$, so $\mu_n \to \frac{(2n-1)\pi}{2}$ (the condition becomes $\phi'(1) = 0$, recovering (ii)). Both limits are the end points of the interval $\left(\frac{(2n-1)\pi}{2}, n\pi\right)$ that contains $\mu_n$.
  • Dimensions: $\lambda\,[\mathrm{L}^{-2}]$ since $\phi'' \sim \phi/\mathrm{L}^2$; with $x$ non-dimensionalised by the length, $\mu$ is dimensionless, as is $h$ (units $\mathrm{L}^{-1}$ before scaling).
  • Orthogonality with weight $\sigma = 1$: e.g. (i), $\int_0^1\sin(n\pi x)\sin(m\pi x)\,dx = \frac12\delta_{nm}$. Barrow check for $n \ne m$: $\frac12\left[\frac{\sin((n-m)\pi x)}{(n-m)\pi} - \frac{\sin((n+m)\pi x)}{(n+m)\pi}\right]_0^1 = 0$.
  • Sign of $\lambda$: the Rayleigh quotient with $p = 1$, $q = 0$ gives $\lambda = \frac{\int(\phi')^2 + h\phi(1)^2}{\int\phi^2} > 0$ in (iv) (boundary term $-[\phi\phi']_0^1 = h\phi(1)^2$ for $h > 0$), which agrees with the direct proof that no $\lambda \le 0$ exists.
Exercise 2

Non-Standard Constant-Coefficient Eigenvalue Problems

Original statement · probls_ch6_2627.pdf
Eigenvalue problems with first-derivative term
Statement

Determine the eigenvalues and eigenfunctions of the following problems:

  1. $y''(x) + y'(x) + (1+\lambda)\,y(x) = 0,\quad y(0) = y(1) = 0$;
  2. $y''(x) + 2y'(x) + (1-\lambda)\,y(x) = 0,\quad y(0) = y'(1) = 0$;
  3. $y''(x) - 3y'(x) + 3(1+\lambda)\,y(x) = 0,\quad y'(0) = y'(1) = 0$.
Formulation and Sturm-Liouville Structure

Each equation has the form $y'' + \alpha y' + [\lambda\beta + \gamma]y = 0$ with constant $\alpha, \beta, \gamma$. The integrating factor $\mu(x) = e^{\alpha x}$ (derived in Problem - Ch6-P3 Integrating Factor for Sturm-Liouville Self-Adjoint Form) turns it into $[\mu y']' + [\lambda\mu\beta + \mu\gamma]y = 0$:

Part$\alpha$$\beta$$\gamma$$p = \mu$$\sigma = \mu\beta$$q = \mu\gamma$
(i)$1$$1$$1$$e^{x}$$e^{x}$$e^{x}$
(ii)$2$$-1$$1$$e^{2x}$$-e^{2x}$$e^{2x}$
(iii)$-3$$3$$3$$e^{-3x}$$3e^{-3x}$$3e^{-3x}$

The characteristic polynomial $r^2 + \alpha r + (\lambda\beta + \gamma) = 0$ has discriminant $\Delta = \alpha^2 - 4(\lambda\beta+\gamma)$. All three signs of $\Delta$ are examined in each part; the value of $\lambda$ at which $\Delta$ changes sign is found first. Method: Notes09-12-Nov.pdf (Sturm-Liouville section; page to be confirmed); Haberman, Sec. 5.3.

Sign of $\sigma$ in (ii)

In (ii) the coefficient of $y$ is $(1 - \lambda)$, so $\sigma = -e^{2x} < 0$. The usual argument "$\lambda > 0$ for $p, \sigma > 0$" is reversed: the eigenvalues turn out to be non-positive.

Eigenvalue Cases (Negative, Zero, Positive)
(i) $y'' + y' + (1+\lambda)y = 0$, $y(0) = y(1) = 0$

Roots: $r = \dfrac{-1 \pm \sqrt{1 - 4(1+\lambda)}}{2} = \dfrac{-1 \pm \sqrt{-3-4\lambda}}{2}$, so $\Delta = -3 - 4\lambda$.

  • $\Delta > 0$, i.e. $\lambda < -3/4$. Put $\nu = \tfrac12\sqrt{-3-4\lambda} > 0$. Then $y = e^{-x/2}(A\cosh\nu x + B\sinh\nu x)$. $y(0) = A = 0$; $y(1) = Be^{-1/2}\sinh\nu = 0$ with $\sinh\nu > 0$, so $B = 0$. Trivial.
  • $\Delta = 0$, i.e. $\lambda = -3/4$. Then $y = e^{-x/2}(c_1 + c_2 x)$. $y(0) = c_1 = 0$; $y(1) = c_2e^{-1/2} = 0$ gives $c_2 = 0$. Trivial.
  • $\Delta < 0$, i.e. $\lambda > -3/4$. Put $\omega^2 = \lambda + \tfrac34 > 0$, so $\sqrt{\Delta} = 2i\omega$ and $r = -\tfrac12 \pm i\omega$. Then $y = e^{-x/2}(A\cos\omega x + B\sin\omega x)$. $y(0) = A = 0$; $y(1) = Be^{-1/2}\sin\omega = 0$, so $\sin\omega = 0$ and $\omega = n\pi$, $n \ge 1$.
(i)

$\lambda_n = n^2\pi^2 - \dfrac34,\quad y_n(x) = e^{-x/2}\sin(n\pi x),\quad n = 1, 2, 3, \dots$

Check of the ODE for $y_n$: $y' = e^{-x/2}\left(-\tfrac12\sin\omega x + \omega\cos\omega x\right)$ (product rule), $y'' = e^{-x/2}\left[\left(\tfrac14 - \omega^2\right)\sin\omega x - \omega\cos\omega x\right]$. Then $y'' + y' + (1+\lambda)y = e^{-x/2}\sin\omega x\left[\tfrac14 - \omega^2 - \tfrac12 + 1 + \lambda\right] + e^{-x/2}\cos\omega x[-\omega + \omega] = e^{-x/2}\sin\omega x\,[\lambda + \tfrac34 - \omega^2] = 0$. ✓.

Orthogonality weight $\sigma = e^{x}$: $\int_0^1 e^{x}y_ny_m\,dx = \int_0^1 e^{x}e^{-x}\sin(n\pi x)\sin(m\pi x)\,dx = \tfrac12\delta_{nm}$.

(ii) $y'' + 2y' + (1-\lambda)y = 0$, $y(0) = y'(1) = 0$

Roots: $r^2 + 2r + (1-\lambda) = 0$ gives $r = -1 \pm \sqrt{\lambda}$ (here $\Delta = 4\lambda$).

  • $\lambda > 0$ ($\Delta > 0$). Put $s = \sqrt\lambda > 0$: $y = e^{-x}(A\cosh sx + B\sinh sx)$; $y(0) = A = 0$, so $y = Be^{-x}\sinh sx$. By the product rule $y' = Be^{-x}(s\cosh sx - \sinh sx)$, so

$$ y'(1) = Be^{-1}\left(s\cosh s - \sinh s\right) = 0 \iff \tanh s = s. $$

Define $g(u) = u - \tanh u$. Then $g(0) = 0$ and $g'(u) = 1 - \operatorname{sech}^2 u = \tanh^2 u > 0$ for $u > 0$. Hence $g$ is strictly increasing, so $g(u) > 0$ and $\tanh u < u$ for all $u > 0$. The equation $\tanh s = s$ has no solution with $s > 0$, so $B = 0$. No eigenvalue with $\lambda > 0$.

  • $\lambda = 0$ ($\Delta = 0$). $y = e^{-x}(c_1 + c_2x)$. $y(0) = c_1 = 0$. Then $y = c_2xe^{-x}$ and $y' = c_2(1-x)e^{-x}$, so $y'(1) = c_2\cdot 0 = 0$ for every $c_2$. The boundary condition holds identically.
$\lambda = 0$ is an eigenvalue

$y_0(x) = xe^{-x}$ satisfies $y_0'' + 2y_0' + y_0 = 0$ (since $(r+1)^2 = 0$ with double root $-1$), $y_0(0) = 0$ and $y_0'(1) = (1-1)e^{-1} = 0$. It is non-trivial, so $\lambda_0 = 0$ is an eigenvalue. This is the limit $s \to 0$ of the root condition $s\cosh s - \sinh s = 0$, which vanishes at $s = 0$ because $g(0) = 0$.

  • $\lambda < 0$ ($\Delta < 0$). Put $\lambda = -\omega^2$, $\omega > 0$: $r = -1 \pm i\omega$, $y = e^{-x}(A\cos\omega x + B\sin\omega x)$. $y(0) = A = 0$, $y = Be^{-x}\sin\omega x$, $y' = Be^{-x}(\omega\cos\omega x - \sin\omega x)$, and

$$ y'(1) = Be^{-1}(\omega\cos\omega - \sin\omega) = 0 \iff \tan\omega = \omega \quad(\cos\omega \ne 0,\text{ otherwise }\sin\omega = \pm1\ne 0). $$

Location of the roots of $\tan\omega = \omega$

Let $h(\omega) = \tan\omega - \omega$, with $h'(\omega) = \tan^2\omega \ge 0$.

  • On $(0, \pi/2)$: $h(0) = 0$ and $h' > 0$ for $\omega > 0$, so $h > 0$: no positive root.
  • On $(n\pi - \pi/2,\ n\pi)$: $\tan\omega \le 0 < \omega$, so $h < 0$: no root.
  • On $\left(n\pi,\ n\pi + \tfrac\pi2\right)$, $n \ge 1$: $h(n\pi) = -n\pi < 0$ and $h \to +\infty$ at the right end; $h$ is strictly increasing, so exactly one root $\omega_n$.

So $\omega_n \in \left(n\pi, \left(n+\tfrac12\right)\pi\right)$: $\omega_1 \approx 4.4934\in(\pi, 3\pi/2)$, $\omega_2 \approx 7.7253$, and $\omega_n \to \left(n+\tfrac12\right)\pi$.

(ii)

$\lambda_0 = 0,\ y_0(x) = xe^{-x}$; and $\lambda_n = -\omega_n^2 < 0,\ y_n(x) = e^{-x}\sin(\omega_nx)$, with $\omega_n$ the root of $\tan\omega = \omega$ in $\left(n\pi, (n+\tfrac12)\pi\right)$, $n = 1, 2, \dots$

Why the eigenvalues are non-positive: $\sigma = -e^{2x} < 0$ (see the table), so the roles of $\lambda$ and $-\lambda$ swap relative to the standard problem. With $y = e^{-x}u$ (Liouville shift, see Problem - Ch6-P3 Integrating Factor for Sturm-Liouville Self-Adjoint Form) the equation becomes $u'' - \lambda u = 0$ with $u(0) = 0$, $u'(1) = u(1)$ (Robin), whose eigenvalue parameter is $-\lambda$, which is $\ge 0$.

Orthogonality, weight $|\sigma| = e^{2x}$: $\int_0^1 e^{2x}y_ny_m\,dx = \int_0^1\sin(\omega_nx)\sin(\omega_mx)\,dx = 0$ for $n \ne m$ (Robin-type problem). Direct check with $y_0$: $\int_0^1 e^{2x}\,xe^{-x}\,e^{-x}\sin\omega_nx\,dx = \int_0^1 x\sin\omega_nx\,dx = \left[-\dfrac{x\cos\omega_nx}{\omega_n}\right]_0^1 + \dfrac1{\omega_n}\int_0^1\cos\omega_nx\,dx = -\dfrac{\cos\omega_n}{\omega_n} + \dfrac{\sin\omega_n}{\omega_n^2}$, which is $0$ because $\sin\omega_n = \omega_n\cos\omega_n$.

(iii) $y'' - 3y' + 3(1+\lambda)y = 0$, $y'(0) = y'(1) = 0$

Roots: $r = \dfrac{3 \pm \sqrt{9 - 12(1+\lambda)}}{2} = \dfrac{3 \pm \sqrt{-3-12\lambda}}{2}$, so $\Delta = -3 - 12\lambda$.

  • $\Delta > 0$, i.e. $\lambda < -1/4$. Put $\mu = \tfrac12\sqrt{-3-12\lambda} = \sqrt{-\tfrac34 - 3\lambda} > 0$, so $r = \tfrac32 \pm \mu$ and $y = e^{3x/2}(A\cosh\mu x + B\sinh\mu x)$. By the product rule

$$ y' = e^{3x/2}\left[\tfrac32(A\cosh\mu x + B\sinh\mu x) + \mu(A\sinh\mu x + B\cosh\mu x)\right]. $$

$y'(0) = 0$: $\tfrac32A + \mu B = 0$. $y'(1) = 0$: $A\left(\tfrac32\cosh\mu + \mu\sinh\mu\right) + B\left(\tfrac32\sinh\mu + \mu\cosh\mu\right) = 0$. The determinant of the $2\times2$ system in $(A, B)$ is

$$ \tfrac32\left(\tfrac32\sinh\mu + \mu\cosh\mu\right) - \mu\left(\tfrac32\cosh\mu + \mu\sinh\mu\right) = \left(\tfrac94 - \mu^2\right)\sinh\mu. $$

With $\sinh\mu > 0$, a non-trivial solution exists only if $\mu = \tfrac32$, that is $-\tfrac34 - 3\lambda = \tfrac94$, so $\lambda = -1$ (consistent with $\lambda < -1/4$). Then $A = -\tfrac{2\mu}{3}B = -B$ and

$$ y = B e^{3x/2}\left(\sinh\tfrac{3x}{2} - \cosh\tfrac{3x}{2}\right) = -B e^{3x/2}e^{-3x/2} = -B. $$

A negative eigenvalue with a constant eigenfunction

At $\lambda = -1$ the equation is $y'' - 3y' = 0$, with general solution $y = c_1 + c_2e^{3x}$. $y' = 3c_2e^{3x}$ and $y'(0) = 3c_2 = 0$ gives $c_2 = 0$, then $y'(1) = 0$ holds. So $y_0(x) = 1$ is an eigenfunction at $\lambda_0 = -1$. Check: $y_0'' - 3y_0' + 3(1 + (-1))y_0 = 0$ ✓, $y_0'(0) = y_0'(1) = 0$ ✓.

  • $\Delta = 0$, i.e. $\lambda = -1/4$. $y = e^{3x/2}(c_1 + c_2x)$, $y' = e^{3x/2}\left[\tfrac32c_1 + \tfrac32c_2x + c_2\right]$. $y'(0) = \tfrac32c_1 + c_2 = 0$; $y'(1) = e^{3/2}\left[\tfrac32c_1 + \tfrac52c_2\right] = 0$. Subtracting: $\tfrac32c_2 = 0$, so $c_2 = 0$ and $c_1 = 0$. Trivial.
  • $\Delta < 0$, i.e. $\lambda > -1/4$. Put $\omega^2 = 3\lambda + \tfrac34 > 0$, so $r = \tfrac32 \pm i\omega$ and $y = e^{3x/2}(A\cos\omega x + B\sin\omega x)$. Then

$$ y' = e^{3x/2}\left[\left(\tfrac32A + \omega B\right)\cos\omega x + \left(\tfrac32B - \omega A\right)\sin\omega x\right]. $$

$y'(0) = \tfrac32A + \omega B = 0$. With this condition the coefficient of $\cos\omega x$ in $y'$ is exactly $0$, so $y'(1) = e^{3/2}\left(\tfrac32B - \omega A\right)\sin\omega = 0$. If $\tfrac32B - \omega A = 0$, then together with $\tfrac32A + \omega B = 0$ the matrix $\begin{pmatrix}\tfrac32 & \omega\\ -\omega & \tfrac32\end{pmatrix}$ has determinant $\tfrac94 + \omega^2 > 0$, so $A = B = 0$ (trivial). Hence $\sin\omega = 0$, $\omega = n\pi$, $n \ge 1$, and $\lambda_n = \dfrac{n^2\pi^2 - 3/4}{3} = \dfrac{n^2\pi^2}{3} - \dfrac14$. Choose $A = 1$; then $B = -\dfrac{3}{2n\pi}$.

(iii)

$\lambda_0 = -1,\ y_0(x) = 1$; and $\lambda_n = \dfrac{n^2\pi^2}{3} - \dfrac14,\quad y_n(x) = e^{3x/2}\left[\cos(n\pi x) - \dfrac{3}{2n\pi}\sin(n\pi x)\right],\quad n = 1, 2, \dots$

Eigenfunctions and Checks
  • Boundary conditions of $y_n$ in (iii), explicitly: $y_n'(0) = \tfrac32\cdot1 + n\pi\left(-\tfrac{3}{2n\pi}\right) = 0$ ✓; $y_n'(1) = e^{3/2}\left[0\cdot\cos n\pi + \left(-\tfrac{9}{4n\pi} - n\pi\right)\sin n\pi\right] = 0$ ✓ (first bracket is $0$, second multiplies $\sin n\pi = 0$).
  • Orthogonality in (iii), weight $\sigma = 3e^{-3x}$: $y_0 = 1$ against $y_n$ gives $\int_0^1 e^{-3x}e^{3x/2}\left[\cos n\pi x - \tfrac{3}{2n\pi}\sin n\pi x\right]dx = \int_0^1\dfrac{1}{n\pi}\dfrac{d}{dx}\left[e^{-3x/2}\sin n\pi x\right]dx$, because $\dfrac{d}{dx}\left[e^{-3x/2}\sin n\pi x\right] = e^{-3x/2}\left(n\pi\cos n\pi x - \tfrac32\sin n\pi x\right)$. By Barrow's rule the value is $\dfrac1{n\pi}\left[e^{-3x/2}\sin n\pi x\right]_0^1 = 0$ ✓.
  • Liouville-shift check ($y = e^{-\alpha x/2}u$ gives $u'' + [\lambda\beta + \gamma - \alpha^2/4]u = 0$): (i) $u'' + (\lambda + \tfrac34)u = 0$; (ii) $u'' - \lambda u = 0$; (iii) $u'' + (3\lambda + \tfrac34)u = 0$. These match $\omega^2 = \lambda + \tfrac34$, $\omega^2 = -\lambda$ and $\omega^2 = 3\lambda + \tfrac34$ above.
  • Dimensions: each term of the ODE has dimension $[y]/\mathrm{L}^2$ with $x$ non-dimensional, so $\lambda$ is dimensionless.
Exercise 3

Integrating Factor for Sturm-Liouville Self-Adjoint Form

Original statement · probls_ch6_2627.pdf
Integrating factor to self-adjoint form
Statement

Consider the ODE $\phi''(x) + \alpha(x)\phi'(x) + [\lambda\beta(x) + \gamma(x)]\phi(x) = 0$. Find an integrating factor $\mu(x)$ in terms of the coefficients of the ODE $\alpha(x)$, $\beta(x)$ and $\gamma(x)$, such that the equation can be brought into Sturm-Liouville form, namely, $[p(x)\phi'(x)]' + [\lambda\sigma(x) + q(x)]\phi(x) = 0$.

Formulation and Sturm-Liouville Structure

Goal: find $\mu(x) > 0$ such that $\mu\cdot\left(\phi'' + \alpha\phi' + [\lambda\beta+\gamma]\phi\right)$ has the form $[p\phi']' + [\lambda\sigma + q]\phi$. Only the derivative terms can obstruct this, since the term in $\phi$ is just rescaled. Method: Notes09-12-Nov.pdf (Sturm-Liouville section; page to be confirmed); Haberman, Sec. 5.3.

Derivation of the Integrating Factor

Multiply the ODE by $\mu(x)$:

$$ \mu\phi'' + \mu\alpha\phi' + \mu[\lambda\beta + \gamma]\phi = 0. $$

Expand the target derivative with the product rule, $[\mu\phi']' = \mu'\phi' + \mu\phi''$. The first two terms above equal $[\mu\phi']'$ if and only if the coefficients of $\phi'$ agree:

$$ \mu\alpha = \mu' \iff \frac{\mu'}{\mu} = \alpha. $$

Since $\mu > 0$, $\dfrac{\mu'}{\mu} = \dfrac{d}{dx}\ln\mu$ (chain rule), and integrating,

$$ \ln\mu(x) = \int\alpha(x)\,dx + C \quad\Longrightarrow\quad \mu(x) = K\exp\left(\int\alpha(x)\,dx\right),\ K = e^{C} > 0. $$

The constant $K$ multiplies the whole equation by a number, so it is irrelevant: take $K = 1$. With limits, $\mu(x) = \exp\left(\int_{x_0}^{x}\alpha(s)\,ds\right)$ for any base point $x_0$ (Barrow's rule gives $\int_{x_0}^x\alpha = A(x) - A(x_0)$, again a constant factor).

Integrating factor and coefficients

$$ \mu(x) = \exp\left(\int\alpha(x)\,dx\right) > 0,\qquad p(x) = \mu(x),\quad \sigma(x) = \mu(x)\beta(x),\quad q(x) = \mu(x)\gamma(x). $$

Product-rule check, written out. With $\mu' = \alpha\mu$:

$$ [\mu\phi']' = \mu'\phi' + \mu\phi'' = \alpha\mu\phi' + \mu\phi'' = \mu(\phi'' + \alpha\phi'), $$

so $\mu(\phi'' + \alpha\phi') + \mu[\lambda\beta + \gamma]\phi = [\mu\phi']' + [\lambda\,\mu\beta + \mu\gamma]\phi = 0$, which is the required form with the identified $p, \sigma, q$ ✓.

Why $\mu$ depends only on $\alpha$

The equation $\mu' = \alpha\mu$ comes from matching the coefficient of $\phi'$. The terms $\lambda\beta\phi$ and $\gamma\phi$ contain no derivative of $\phi$, so they never enter a product-rule expansion: multiplying by any $\mu$ just rescales them into $\sigma$ and $q$. Therefore $\beta$ and $\gamma$ cannot change $\mu$; they only pass through to $\sigma = \mu\beta$ and $q = \mu\gamma$.

Conditions for a Regular Sturm-Liouville Form
  • $p = \mu = e^{\int\alpha} > 0$ automatically, and $p \in C^1$ whenever $\alpha$ is continuous. ($p' = \alpha p$.)
  • $\sigma = \mu\beta > 0 \iff \beta > 0$, because $\mu > 0$. So the weight is positive exactly when the coefficient of $\lambda$ is positive. If $\beta < 0$ (as in Exercise 2(ii), where $\beta = -1$), the weight is negative and the eigenvalues have the opposite sign to the standard expectation; replacing $\lambda$ by $-\lambda$ restores $\sigma > 0$.
  • $q = \mu\gamma$ is continuous when $\gamma$ is; its sign has no effect on regularity (it only shifts the spectrum).
  • On a finite closed interval with $p, \sigma > 0$ and $p, p', q, \sigma$ continuous the problem is regular, and orthogonality of eigenfunctions holds with weight $\sigma$: $\int_a^b\sigma\phi_n\phi_m\,dx = 0$ for $\lambda_n \ne \lambda_m$.

Exercise 4

Euler-Cauchy Eigenvalue Problem and Rayleigh Quotient

Original statement · probls_ch6_2627.pdf
Euler-Cauchy eigenproblem and Rayleigh quotient
Statement

Consider the eigenvalue problem $x^2\phi''(x) + x\phi'(x) + \lambda\phi(x) = 0$ on the interval $[1, 2]$, with boundary conditions $\phi(1) = \phi(2) = 0$.

  1. Show that multiplying by $1/x$ puts this equation into Sturm-Liouville form.
  2. Show that $\lambda \ge 0$, and determine all possible eigenvalues. Is $\lambda = 0$ an eigenvalue?
  3. What are the eigenfunctions?
Formulation and Sturm-Liouville Structure

Multiply the equation by $1/x$ (allowed since $x \in [1,2]$, $x \ne 0$):

$$ x\phi'' + \phi' + \frac{\lambda}{x}\phi = 0. $$

By the product rule $(x\phi')' = \phi' + x\phi''$, so

$$ \boxed{(x\phi')' + \frac{\lambda}{x}\phi = 0} $$

which is $[p\phi']' + [\lambda\sigma + q]\phi = 0$ with

$$ p(x) = x > 0,\qquad \sigma(x) = \frac1x > 0,\qquad q(x) = 0\qquad\text{on }[1,2]. $$

This agrees with the integrating factor of Problem - Ch6-P3 Integrating Factor for Sturm-Liouville Self-Adjoint Form: dividing the original equation by $x^2$ gives $\alpha = 1/x$, so $\mu = e^{\ln x} = x$ and $\sigma = \mu\beta = x\cdot x^{-2} = 1/x$. The problem is regular: $p, p', \sigma, q$ are continuous and $p, \sigma > 0$ on the closed interval. Method: Notes09-12-Nov.pdf (Sturm-Liouville section; page to be confirmed); Haberman, Sec. 5.3 and the Rayleigh quotient discussion that follows it.

Positivity via the Rayleigh Quotient

Let $\phi$ be a real eigenfunction (self-adjointness of the regular problem guarantees real eigenvalues and real eigenfunctions). Multiply $(x\phi')' + \frac\lambda x\phi = 0$ by $\phi$ and integrate over $[1,2]$:

$$ \int_1^2\phi\,(x\phi')'\,dx + \lambda\int_1^2\frac{\phi^2}{x}\,dx = 0. $$

Integrate the first term by parts, $u = \phi$, $dv = (x\phi')'\,dx$, $du = \phi'\,dx$, $v = x\phi'$, and apply Barrow's rule to the boundary term:

$$ \int_1^2\phi\,(x\phi')'\,dx = \Big[x\,\phi\,\phi'\Big]_1^2 - \int_1^2x\,(\phi')^2\,dx = 2\phi(2)\phi'(2) - 1\cdot\phi(1)\phi'(1) - \int_1^2x(\phi')^2dx. $$

Because $\phi(1) = \phi(2) = 0$, the boundary term is $0 - 0 = 0$. Hence

$$ \boxed{\lambda = \frac{\displaystyle\int_1^2x\,(\phi')^2\,dx}{\displaystyle\int_1^2\frac{\phi^2}{x}\,dx}\ \ge\ 0.} $$

The denominator is positive for $\phi \not\equiv 0$ (the integrand $\phi^2/x$ is continuous and non-negative, and $1/x > 0$), and the numerator is $\ge 0$ because $x > 0$. So $\lambda \ge 0$.

$\lambda = 0$ is not an eigenvalue

If $\lambda = 0$ then the numerator vanishes: $\int_1^2x(\phi')^2dx = 0$. The integrand is continuous, non-negative and $x \ge 1 > 0$, so $(\phi')^2 \equiv 0$, i.e. $\phi' \equiv 0$ and $\phi \equiv c$. Then $\phi(1) = c = 0$, so $\phi \equiv 0$. Direct check: for $\lambda = 0$ the equation $(x\phi')' = 0$ gives $x\phi' = c_1$, $\phi = c_1\ln x + c_2$; $\phi(1) = c_2 = 0$ and $\phi(2) = c_1\ln2 = 0$ gives $c_1 = 0$. Only the trivial solution, so $\lambda = 0$ is not an eigenvalue and in fact $\lambda > 0$ strictly.

Eigenvalue Cases (Negative, Zero, Positive)

Solve with the Euler substitution $t = \ln x$, i.e. $x = e^{t}$, $t \in [0, \ln2]$. Write $\phi(x) = \Phi(t(x))$.

  • Chain rule: $\phi' = \Phi'(t)\dfrac{dt}{dx} = \dfrac{\Phi'}{x}$.
  • Product rule and chain rule again: $\phi'' = \dfrac{d}{dx}\left(\dfrac{\Phi'}{x}\right) = -\dfrac{\Phi'}{x^2} + \dfrac1x\Phi''\dfrac1x = \dfrac{\Phi'' - \Phi'}{x^2}$.
  • Hence $x^2\phi'' = \Phi'' - \Phi'$ and $x\phi' = \Phi'$, so $x^2\phi'' + x\phi' + \lambda\phi = \Phi'' - \Phi' + \Phi' + \lambda\Phi = \Phi'' + \lambda\Phi$.

The problem becomes the constant-coefficient one

$$ \Phi''(t) + \lambda\Phi(t) = 0,\qquad \Phi(0) = \Phi(\ln2) = 0 $$

(since $t(1) = \ln1 = 0$ and $t(2) = \ln2$). This is Exercise 1(i) on an interval of length $L = \ln2$. All three signs, for completeness (item 2 already excludes $\lambda < 0$ and $\lambda = 0$ through the quotient):

  • $\lambda < 0$, $\lambda = -\mu^2$: $\Phi = A\cosh\mu t + B\sinh\mu t$, $\Phi(0) = A = 0$, $\Phi(\ln2) = B\sinh(\mu\ln2) = 0$ with $\sinh(\mu\ln2) > 0$, so $B = 0$. Trivial.
  • $\lambda = 0$: $\Phi = A + Bt$, $A = 0$, $B\ln2 = 0$. Trivial.
  • $\lambda = \mu^2 > 0$: $\Phi = A\cos\mu t + B\sin\mu t$, $A = 0$, $B\sin(\mu\ln2) = 0$, so $\mu\ln2 = n\pi$, $\mu = \dfrac{n\pi}{\ln2}$, $n = 1, 2, \dots$
Eigenvalues and eigenfunctions

$$ \lambda_n = \left(\frac{n\pi}{\ln2}\right)^2,\qquad \phi_n(x) = \sin\!\left(\frac{n\pi\ln x}{\ln2}\right),\qquad n = 1, 2, 3, \dots $$

All $\lambda_n > 0$, so $\lambda = 0$ is not an eigenvalue, consistent with the Rayleigh argument.

Eigenfunctions and Checks
  • Boundary conditions: $\phi_n(1) = \sin(n\pi\cdot 0) = \sin0 = 0$ and $\phi_n(2) = \sin(n\pi\ln2/\ln2) = \sin n\pi = 0$ ✓.
  • Direct ODE check (chain rule): $\phi_n' = \dfrac{n\pi}{x\ln2}\cos\!\left(\dfrac{n\pi\ln x}{\ln2}\right)$, and $(x\phi_n')' = \dfrac{d}{dx}\left[\dfrac{n\pi}{\ln2}\cos\!\left(\dfrac{n\pi\ln x}{\ln2}\right)\right] = -\left(\dfrac{n\pi}{\ln2}\right)^2\dfrac1x\sin\!\left(\dfrac{n\pi\ln x}{\ln2}\right)$, so $(x\phi_n')' + \dfrac{\lambda_n}{x}\phi_n = 0$ ✓.
  • Rayleigh quotient value: $\int_1^2x(\phi_n')^2dx = \left(\dfrac{n\pi}{\ln2}\right)^2\int_1^2\dfrac1x\cos^2(\dots)dx$ and $\int_1^2\dfrac{\phi_n^2}{x}dx = \int_1^2\dfrac1x\sin^2(\dots)dx$. With $t = \ln x$, $dt = dx/x$: both integrals equal $\int_0^{\ln2}\cos^2$ or $\sin^2\left(\tfrac{n\pi t}{\ln2}\right)dt = \dfrac{\ln2}{2}$, so the quotient is $\left(\dfrac{n\pi}{\ln2}\right)^2 = \lambda_n$ ✓.
  • Orthogonality with weight $\sigma(x) = 1/x$: for $n \ne m$, with $t = \ln x$,

$$ \int_1^2\frac1x\sin\!\left(\frac{n\pi\ln x}{\ln2}\right)\sin\!\left(\frac{m\pi\ln x}{\ln2}\right)dx = \int_0^{\ln2}\sin\frac{n\pi t}{\ln2}\sin\frac{m\pi t}{\ln2}\,dt = \frac{\ln2}{2}\delta_{nm}. $$

Barrow check for $n \ne m$: $\tfrac12\left[\dfrac{\ln2\,\sin((n-m)\pi t/\ln2)}{(n-m)\pi} - \dfrac{\ln2\,\sin((n+m)\pi t/\ln2)}{(n+m)\pi}\right]_0^{\ln2} = 0$ since $\sin(k\pi) = 0$.

  • Dimensions: $x$ is a non-dimensional (scaled) coordinate, so $\ln x$ is well defined and $\lambda$ is dimensionless. Limiting case: on an interval $[1, b]$ the same steps give $\lambda_n = (n\pi/\ln b)^2$, which grows without bound as $b \to 1^+$ (a shrinking interval forces large eigenvalues, as for $\phi'' + \lambda\phi = 0$ on a short interval).
Exercise 5

Fourier Series of Nine Functions

Original statement · probls_ch6_2627.pdf
Nine Fourier series
Statement

Calculate the Fourier series for the given functions:

(i) $f(x) = 1$, $-\pi \le x \le \pi$; (ii) $f(x) = x$, $-\pi \le x \le \pi$; (iii) $f(x) = \pi - x$, $-\pi \le x \le \pi$; (iv) $f(x) = |x|$, $-\pi \le x \le \pi$; (v) $f(x) = x^2$, $-\pi \le x \le \pi$; (vi) $f(x) = \cos x$, $0 \le x \le \pi$; (vii) $f(x) = \begin{cases} 0, & -\pi \le x < 0, \\ \pi, & 0 \le x \le \pi; \end{cases}$ (viii) $f(x) = \begin{cases} -\pi/2, & -\pi \le x < 0, \\ \pi/2, & 0 \le x \le \pi; \end{cases}$ (ix) $f(x) = \begin{cases} 1, & 0 \le x \le \pi/2, \\ 2, & \pi/2 \le x \le \pi. \end{cases}$

Period, Symmetry and Coefficient Formulas

For a function of period $2L$ the series is (Haberman, Sec. 3.3)

$$ f(x) \sim a_0 + \sum_{n=1}^{\infty}\left[a_n\cos\frac{n\pi x}{L} + b_n\sin\frac{n\pi x}{L}\right], $$

$$ a_0 = \frac{1}{2L}\int_{-L}^{L} f\,dx,\qquad a_n = \frac{1}{L}\int_{-L}^{L} f\cos\frac{n\pi x}{L}\,dx,\qquad b_n = \frac{1}{L}\int_{-L}^{L} f\sin\frac{n\pi x}{L}\,dx . $$

Here $a_0$ is the mean value of $f$ over a period. For (i) to (v), (vii), (viii) we take $L=\pi$. Parity shortens the work (Haberman, Sec. 3.4; see Problem - Ch6-P9 Fourier Series of Even and Odd Periodic Functions): if $f$ is even, $b_n=0$ and $a_n=\frac{2}{\pi}\int_0^\pi f\cos nx\,dx$; if $f$ is odd, $a_0=a_n=0$ and $b_n=\frac{2}{\pi}\int_0^\pi f\sin nx\,dx$.

Two integrals used repeatedly, for integer $n\ge1$, with $\sin n\pi = 0$ and $\cos n\pi=(-1)^n$:

$$ \int_0^\pi \sin nx\,dx = \left[-\frac{\cos nx}{n}\right]_0^\pi = \frac{1-(-1)^n}{n},\qquad \int_0^\pi \cos nx\,dx = \left[\frac{\sin nx}{n}\right]_0^\pi = 0 . $$

Convergence (Fourier's theorem): at a point where the $2L$-periodic extension is continuous the series equals $f$; at a jump it equals $\tfrac12[f(x^+)+f(x^-)]$.

Step-by-Step Coefficient Evaluation
(i) $f(x)=1$

Even. $a_0=\frac{1}{2\pi}\int_{-\pi}^{\pi}1\,dx=1$, $a_n=\frac{2}{\pi}\int_0^\pi\cos nx\,dx=0$, $b_n=0$. The series is $1$ (it is its own series, trivially).

(ii) $f(x)=x$

Odd, so $a_0=a_n=0$. $b_n=\frac{2}{\pi}\int_0^\pi x\sin nx\,dx$. Integration by parts with $u=x$, $dv=\sin nx\,dx$, $du=dx$, $v=-\frac{\cos nx}{n}$:

$$ \int_0^\pi x\sin nx\,dx=\left[-\frac{x\cos nx}{n}\right]_0^\pi+\frac1n\int_0^\pi\cos nx\,dx=-\frac{\pi(-1)^n}{n}-0+0=\frac{\pi(-1)^{n+1}}{n}. $$

Hence $b_n=\dfrac{2(-1)^{n+1}}{n}$ and

$$ x\sim 2\sum_{n=1}^{\infty}\frac{(-1)^{n+1}}{n}\sin nx . $$

The $2\pi$-periodic extension jumps at $x=\pm\pi$ (from $\pi$ to $-\pi$): the series gives $\tfrac12(\pi-\pi)=0$, which matches $\sin n\pi=0$. At interior points it equals $x$.

(iii) $f(x)=\pi-x$

By linearity $f=\pi + (-x)$: $a_0=\pi$, $a_n=0$, $b_n=-\dfrac{2(-1)^{n+1}}{n}=\dfrac{2(-1)^n}{n}$.

$$ \pi-x\sim \pi+2\sum_{n=1}^{\infty}\frac{(-1)^n}{n}\sin nx . $$

At $x=\pm\pi$: $f(\pi^-)=0$ and $f(-\pi^+)=2\pi$, so the series gives $\tfrac12(0+2\pi)=\pi=a_0$, consistent with every sine vanishing.

(iv) $f(x)=|x|$

Even, $b_n=0$. $a_0=\frac{1}{2\pi}\cdot 2\int_0^\pi x\,dx=\frac1\pi\left[\frac{x^2}{2}\right]_0^\pi=\frac{\pi}{2}$. For $n\ge1$, $a_n=\frac2\pi\int_0^\pi x\cos nx\,dx$ with $u=x$, $dv=\cos nx\,dx$, $du=dx$, $v=\frac{\sin nx}{n}$:

$$ \int_0^\pi x\cos nx\,dx=\left[\frac{x\sin nx}{n}\right]_0^\pi-\frac1n\int_0^\pi\sin nx\,dx=0-\frac1n\cdot\frac{1-(-1)^n}{n}=\frac{(-1)^n-1}{n^2}. $$

So $a_n=\dfrac{2\left((-1)^n-1\right)}{\pi n^2}$, equal to $-\dfrac{4}{\pi n^2}$ for odd $n$ and $0$ for even $n$. With $n=2k-1$:

$$ |x|\sim\frac{\pi}{2}-\frac4\pi\sum_{k=1}^{\infty}\frac{\cos\left((2k-1)x\right)}{(2k-1)^2}. $$

The periodic extension is continuous (since $f(-\pi)=f(\pi)=\pi$), so the series equals $|x|$ everywhere. At $x=0$: $0=\frac\pi2-\frac4\pi S$, so

$$ \sum_{k=1}^{\infty}\frac{1}{(2k-1)^2}=\frac{\pi^2}{8}. $$

(v) $f(x)=x^2$

Even, $b_n=0$. $a_0=\frac1\pi\int_0^\pi x^2dx=\frac1\pi\cdot\frac{\pi^3}{3}=\frac{\pi^2}{3}$. For $a_n=\frac2\pi\int_0^\pi x^2\cos nx\,dx$, first by parts with $u=x^2$, $dv=\cos nx\,dx$, $du=2x\,dx$, $v=\frac{\sin nx}{n}$:

$$ \int_0^\pi x^2\cos nx\,dx=\left[\frac{x^2\sin nx}{n}\right]_0^\pi-\frac2n\int_0^\pi x\sin nx\,dx=0-\frac2n\cdot\frac{\pi(-1)^{n+1}}{n}=\frac{2\pi(-1)^n}{n^2}, $$

using the integral of (ii). Then $a_n=\dfrac{4(-1)^n}{n^2}$ and

$$ x^2\sim\frac{\pi^2}{3}+4\sum_{n=1}^{\infty}\frac{(-1)^n}{n^2}\cos nx . $$

The extension is continuous, so equality holds on $[-\pi,\pi]$.

  • At $x=\pi$: $\pi^2=\frac{\pi^2}{3}+4\sum\frac{(-1)^n(-1)^n}{n^2}$, so $\sum_{n=1}^{\infty}\frac1{n^2}=\frac{\pi^2}{6}$.
  • At $x=0$: $0=\frac{\pi^2}{3}+4\sum\frac{(-1)^n}{n^2}$, so $\sum_{n=1}^{\infty}\frac{(-1)^{n-1}}{n^2}=\frac{\pi^2}{12}$.
(vi) $f(x)=\cos x$ on $[0,\pi]$

The function is given only on $[0,\pi]$, so the natural choice is the $\pi$-periodic extension: period $2L=\pi$, $L=\pi/2$, basis $\cos 2nx$, $\sin 2nx$.

$a_0=\frac1\pi\int_0^\pi\cos x\,dx=\frac1\pi[\sin x]_0^\pi=0$.

Product-to-sum: $\cos x\cos 2nx=\tfrac12\left[\cos(2n+1)x+\cos(2n-1)x\right]$ and $\cos x\sin 2nx=\tfrac12\left[\sin(2n+1)x+\sin(2n-1)x\right]$. For odd $m$, $\int_0^\pi\cos mx\,dx=\frac{\sin m\pi}{m}=0$ and $\int_0^\pi\sin mx\,dx=\frac{1-\cos m\pi}{m}=\frac2m$. Therefore

$$ a_n=\frac2\pi\cdot\tfrac12\cdot 0=0,\qquad b_n=\frac2\pi\cdot\tfrac12\left[\frac{2}{2n+1}+\frac{2}{2n-1}\right]=\frac2\pi\cdot\frac{4n}{4n^2-1}=\frac{8n}{\pi(4n^2-1)} . $$

$$ \cos x\sim\sum_{n=1}^{\infty}\frac{8n}{\pi(4n^2-1)}\sin 2nx . $$

Convergence: the $\pi$-periodic extension has $f(0^+)=1$, $f(\pi^-)=-1$, so it jumps at $x=k\pi$ and the series gives $0$ there (all sines vanish). In $(0,\pi)$ the series equals $\cos x$.

Relation to the half-range expansions on $[0,\pi]$

With $L=\pi$, the odd extension gives $B_m=\frac2\pi\int_0^\pi\cos x\sin mx\,dx=\frac1\pi\left[\frac{1-\cos(m+1)\pi}{m+1}+\frac{1-\cos(m-1)\pi}{m-1}\right]$ for $m\ne1$. For odd $m$ both numerators vanish, so $B_{2n-1}=0$. For $m=2n$ it is $\frac1\pi\left[\frac2{2n+1}+\frac2{2n-1}\right]=\frac{8n}{\pi(4n^2-1)}$, and $B_1=\frac2\pi\int_0^\pi\cos x\sin x\,dx=\frac1\pi\int_0^\pi\sin 2x\,dx=0$. The half-range sine series is therefore the same series as above: $b_{2n}$ survives and $b_{2n-1}=0$. The even (cosine) half-range series is trivially $\cos x$ itself ($a_1=1$, all other coefficients zero, by orthogonality; see Problem - Ch6-P6 Fourier Series via Trigonometric Identities without Integrating).

(vii) Step function $0$ on $[-\pi,0)$, $\pi$ on $[0,\pi]$

$a_0=\frac{1}{2\pi}\int_0^\pi\pi\,dx=\frac\pi2$. $a_n=\frac1\pi\int_0^\pi\pi\cos nx\,dx=0$. $b_n=\frac1\pi\int_0^\pi\pi\sin nx\,dx=\frac{1-(-1)^n}{n}$, which is $\frac2n$ for odd $n$ and $0$ for even $n$.

$$ f\sim\frac\pi2+2\sum_{k=1}^{\infty}\frac{\sin\left((2k-1)x\right)}{2k-1}. $$

At the jumps $x=0,\pm\pi$ the series gives $\frac\pi2=\tfrac12\left(0+\pi\right)$ as required. Check at $x=\pi/2$ (continuity point, $f=\pi$): $\sin\frac{(2k-1)\pi}2=(-1)^{k-1}$ and $\sum\frac{(-1)^{k-1}}{2k-1}=\frac\pi4$ (Leibniz), so $\frac\pi2+2\cdot\frac\pi4=\pi$.

(viii) Step function $-\pi/2$ on $[-\pi,0)$, $\pi/2$ on $[0,\pi]$

This is (vii) minus $\pi/2$, so only $a_0$ changes: $a_0=0$. The function is odd (apart from its value at the jump), and

$$ f\sim2\sum_{k=1}^{\infty}\frac{\sin\left((2k-1)x\right)}{2k-1}. $$

At $x=0$ the series gives $0=\tfrac12\left(-\frac\pi2+\frac\pi2\right)$; at $x=\pi/2$ it gives $2\cdot\frac\pi4=\frac\pi2=f$.

(ix) $f=1$ on $[0,\pi/2]$, $f=2$ on $[\pi/2,\pi]$

Full $\pi$-periodic series ($L=\pi/2$, basis $\cos2nx$, $\sin2nx$):

$a_0=\frac1\pi\left[\frac\pi2\cdot1+\frac\pi2\cdot2\right]=\frac32$.

$a_n=\frac2\pi\left[\int_0^{\pi/2}\cos2nx\,dx+2\int_{\pi/2}^{\pi}\cos2nx\,dx\right]=\frac2\pi\left[\frac{\sin n\pi}{2n}+2\cdot\frac{\sin2n\pi-\sin n\pi}{2n}\right]=0.$

For $b_n$: $\int_0^{\pi/2}\sin2nx\,dx=\left[-\frac{\cos2nx}{2n}\right]_0^{\pi/2}=\frac{1-(-1)^n}{2n}$ and $\int_{\pi/2}^{\pi}\sin2nx\,dx=\frac{(-1)^n-1}{2n}$. Then

$$ b_n=\frac2\pi\left[\frac{1-(-1)^n}{2n}+2\cdot\frac{(-1)^n-1}{2n}\right]=\frac2\pi\cdot\frac{(-1)^n-1}{2n}=\frac{(-1)^n-1}{n\pi}, $$

so $b_{2k}=0$ and $b_{2k-1}=-\dfrac{2}{\pi(2k-1)}$:

$$ f\sim\frac32-\frac2\pi\sum_{k=1}^{\infty}\frac{\sin\left(2(2k-1)x\right)}{2k-1}. $$

Check at $x=\pi/4$ ($f=1$): $\sin\frac{(2k-1)\pi}{2}=(-1)^{k-1}$, so $\frac32-\frac2\pi\cdot\frac\pi4=1$. At the jump $x=\pi/2$ the series gives $\frac32=\tfrac12(1+2)$.

Half-range cosine series on $[0,\pi]$ ($L=\pi$, even extension): $a_0=\frac32$ and, evaluating each antiderivative by Barrow's rule with substitution $u = nx$,

$$ a_n=\frac2\pi\left[\int_0^{\pi/2}\cos nx\,dx+2\int_{\pi/2}^{\pi}\cos nx\,dx\right]=\frac2\pi\left(\left[\frac{\sin nx}{n}\right]_0^{\pi/2}+2\left[\frac{\sin nx}{n}\right]_{\pi/2}^{\pi}\right)=\frac2\pi\left[\frac{\sin(n\pi/2)}{n}-\frac{2\sin(n\pi/2)}{n}\right]=-\frac{2\sin(n\pi/2)}{n\pi}. $$

Only odd $n=2k-1$ survive, with $\sin\frac{(2k-1)\pi}2=(-1)^{k-1}$:

$$ f\sim\frac32-\frac2\pi\sum_{k=1}^{\infty}\frac{(-1)^{k-1}}{2k-1}\cos\left((2k-1)x\right). $$

The even extension has a single jump in $(0,\pi)$ (at $\pi/2$, mirrored at $-\pi/2$) and is continuous at $0$ and $\pi$.

Half-range sine series on $[0,\pi]$ ($L=\pi$, odd extension): $a_0=a_n=0$, and applying Barrow's rule with $u = nx$, $\int_0^{\pi/2}\sin nx\,dx=\left[-\frac{\cos nx}{n}\right]_0^{\pi/2}=\frac{1-\cos(n\pi/2)}{n}$ and $\int_{\pi/2}^{\pi}\sin nx\,dx=\left[-\frac{\cos nx}{n}\right]_{\pi/2}^{\pi}=\frac{\cos(n\pi/2)-\cos n\pi}{n}$, so

$$ b_n=\frac2\pi\left[\frac{1-\cos(n\pi/2)}{n}+2\,\frac{\cos(n\pi/2)-\cos n\pi}{n}\right]=\frac{2}{n\pi}\left(1+\cos\frac{n\pi}2-2(-1)^n\right). $$

$$ f\sim\sum_{n=1}^{\infty}\frac{2}{n\pi}\left(1+\cos\frac{n\pi}2-2(-1)^n\right)\sin nx=\frac6\pi\sin x-\frac2\pi\sin2x+\frac2\pi\sin3x+0\cdot\sin4x+\cdots $$

(values: $b_1=\frac{6}{\pi}$, $b_2=-\frac2\pi$, $b_3=\frac2\pi$, $b_4=0$). The odd extension jumps at $x=0,\pm\pi$ (where the series gives $0$) and at $\pm\pi/2$.

Fourier Series via Trigonometric Identities without Integrating

Original statement · probls_ch6_2627.pdf, p. 2
Series from identities
Statement

Compute the Fourier series of the following functions in $[-\pi,\pi]$: $f(x)=\sin2x$, $f(x)=2+3\cos(2x)$, $f(x)=\sin(4x)$, $f(x)=8\cos^3(3x)$. Can you compute the Fourier series without using the integral formulas for the coefficients in these cases?

Why the Answer Is Yes: Uniqueness of the Coefficients

On $[-\pi,\pi]$ ($L=\pi$) the series is $a_0+\sum_{n\ge1}(a_n\cos nx+b_n\sin nx)$ with the coefficient formulas of Problem - Ch6-P5 Fourier Series of Nine Functions. The orthogonality relations proved in Problem - Ch6-P7 Orthogonality Relations of Sine and Cosine Families say that $\{1,\cos nx,\sin nx\}$ is an orthogonal family with $\int_{-\pi}^{\pi}\cos^2nx\,dx=\int_{-\pi}^{\pi}\sin^2nx\,dx=\pi$, $\int_{-\pi}^{\pi}1\,dx=2\pi$.

Suppose $f$ is already a finite trigonometric polynomial, $f=c_0+\sum_{n=1}^{N}(\alpha_n\cos nx+\beta_n\sin nx)$. Insert it in $a_m=\frac1\pi\int f\cos mx\,dx$. By linearity and orthogonality every term vanishes except the one containing $\cos mx$, which gives $\frac1\pi\cdot\alpha_m\cdot\pi=\alpha_m$. The same argument gives $b_m=\beta_m$ and $a_0=c_0$ (the sum is finite, so integrating term by term is legitimate). Hence the Fourier coefficients of a trigonometric polynomial are the coefficients with which it is written, and the series is the polynomial itself: the only work is to rewrite $f$ as a combination of $1$, $\cos nx$, $\sin nx$ (Haberman, Sec. 3.3).

Orthogonality Relations of Sine and Cosine Families

Original statement · probls_ch6_2627.pdf, p. 2
Orthogonality proofs
Statement

Show that the functions $y_n(x)=\sin\left(\frac{n\pi x}{L}\right)$ satisfy

$$ \int_{-L}^{L}y_n(x)y_m(x)\,dx=\begin{cases}0,&n\ne m,\\ L,&n=m,\end{cases}\qquad m,n=0,1,2,\dots $$

Show that a similar property holds for $u_n(x)=\cos\left(\frac{n\pi x}{L}\right)$:

$$ \int_{-L}^{L}u_n(x)u_m(x)\,dx=\begin{cases}0,&n\ne m,\\ L,&n=m\ne0,\\ 2L,&n=m=0,\end{cases}\qquad m,n=0,1,2,\dots $$

Tools: Product-to-Sum Identities and One Basic Integral

From $\cos(A\mp B)=\cos A\cos B\pm\sin A\sin B$ (subtract and add):

$$ \sin A\sin B=\tfrac12\left[\cos(A-B)-\cos(A+B)\right],\qquad\cos A\cos B=\tfrac12\left[\cos(A-B)+\cos(A+B)\right]. $$

Basic integral. For an integer $k$, put $I_k=\int_{-L}^{L}\cos\frac{k\pi x}{L}\,dx$.

  • If $k\ne0$, the antiderivative is $\frac{L}{k\pi}\sin\frac{k\pi x}{L}$ and by Barrow's rule $I_k=\frac{L}{k\pi}\left[\sin k\pi-\sin(-k\pi)\right]=\frac{2L\sin k\pi}{k\pi}=0$, since $\sin k\pi=0$ for integer $k$.
  • If $k=0$, $I_0=\int_{-L}^{L}dx=[x]_{-L}^{L}=2L$.

So $I_k=2L\,\delta_{k0}$.

Sines

Take $A=\frac{n\pi x}{L}$, $B=\frac{m\pi x}{L}$:

$$ \int_{-L}^{L}y_ny_m\,dx=\tfrac12\left[I_{n-m}-I_{n+m}\right]. $$

  • $n\ne m$: $n-m\ne0$ gives $I_{n-m}=0$; $n+m\ge1$ (the pair cannot be $(0,0)$) gives $I_{n+m}=0$. The integral is $0$.
  • $n=m\ge1$: $I_0=2L$ and $I_{2n}=0$ (as $2n\ne0$), so the integral is $\tfrac12(2L-0)=L$.
  • Edge case $n=m=0$: here $y_0(x)=\sin0=0$ identically, so $\int_{-L}^{L}0\,dx=0$. The formula $\frac12[I_0-I_0]=0$ confirms it. Therefore the value $L$ holds only for $n=m\ge1$ (and $y_0$ is the zero function, not a genuine eigenfunction). Likewise if exactly one of $n,m$ is $0$, the integrand is $0$ and the result $0$ agrees with the case $n\ne m$.
Cosines

$$ \int_{-L}^{L}u_nu_m\,dx=\tfrac12\left[I_{n-m}+I_{n+m}\right]. $$

  • $n\ne m$: $I_{n-m}=0$, $I_{n+m}=0$ ($n+m\ge1$), so $0$.
  • $n=m\ge1$: $\tfrac12\left[I_0+I_{2n}\right]=\tfrac12(2L+0)=L$.
  • $n=m=0$: $u_0=1$, and directly $\int_{-L}^{L}1\,dx=2L$ (in the formula $\tfrac12[I_0+I_0]=2L$).
Result and Checks
Orthogonality

$$ \int_{-L}^{L}\sin\frac{n\pi x}{L}\sin\frac{m\pi x}{L}dx=L\,\delta_{nm}\ (n,m\ge1),\qquad\int_{-L}^{L}\cos\frac{n\pi x}{L}\cos\frac{m\pi x}{L}dx=\begin{cases}L\,\delta_{nm},&n\ \text{or}\ m\ge1,\\2L,&n=m=0.\end{cases} $$

These are the relations behind the coefficient formulas $a_n=\frac1L\int f\cos$ and $b_n=\frac1L\int f\sin$ (Problem - Ch6-P5 Fourier Series of Nine Functions; Haberman, Sec. 3.3).

Checks. Dimensions: $[y_n]$ is dimensionless, so the integral has dimension of $L$ ✓. Limiting check $L=\pi$, $n=m=1$: $\int_{-\pi}^{\pi}\sin^2x\,dx=\int\frac{1-\cos2x}{2}dx=\pi$ ✓. The two parity facts are also visible directly: $\sin\cdot\sin$ is even in $x$, so the integral is twice $\int_0^L$ and the same Barrow evaluations give the same numbers.

Sketching Fourier series
Statement

Sketch the Fourier series of $f(x)$ on $[-L,L]$ for the given function, and compare with the graph of $f(x)$ itself.

(i) $f(x)=x^2$; (ii) $f(x)=e^x$; (iii) $f(x)=\begin{cases}1,&x<0,\\x+1,&x\ge0.\end{cases}$

Period, Extension and Convergence Rule

The Fourier series of $f$ on $[-L,L]$ is $a_0+\sum\left(a_n\cos\frac{n\pi x}{L}+b_n\sin\frac{n\pi x}{L}\right)$, with $a_0=\frac{1}{2L}\int_{-L}^{L}f\,dx$, $a_n=\frac1L\int f\cos\frac{n\pi x}L dx$, $b_n=\frac1L\int f\sin\frac{n\pi x}L dx$. It is a $2L$-periodic function, so the sketch is the graph of the $2L$-periodic extension of $f$, with the value at each discontinuity replaced by the average of the one-sided limits (Fourier's Convergence Theorem; Haberman, Sec. 3.4).

Procedure: extend $f$ by $f(x+2L)=f(x)$; test continuity inside $(-L,L)$ and at the junctions $x=(2k+1)L$, where $f(L^-)$ meets $f(-L^+)$; at a continuity point the series equals $f$; at a jump it equals $\frac12[f(x^+)+f(x^-)]$. Below $k=\frac{n\pi}{L}$ abbreviates the frequency and $\sin n\pi=0$, $\cos n\pi=(-1)^n$.

Exercise 9

Fourier Series of Even and Odd Periodic Functions

Original statement · probls_ch6_2627.pdf, p. 2
Even and odd series
Statement

What can we say about the Fourier series on $[-L,L]$ of a function $f(x)$ that is $2L$ periodic and even, that is, satisfies $f(-x)=f(x)$ for $x\in\mathbb R$? And if $f(x)$ is $2L$ periodic and odd, $f(-x)=-f(x)$?

Period, Symmetry and Coefficient Formulas

With $k=\frac{n\pi}{L}$: $a_0=\frac1{2L}\int_{-L}^{L}f\,dx$, $a_n=\frac1L\int_{-L}^{L}f\cos kx\,dx$, $b_n=\frac1L\int_{-L}^{L}f\sin kx\,dx$ (Haberman, Sec. 3.4). Parities of the basis: $\cos kx$ is even and $\sin kx$ is odd, because $\cos(-kx)=\cos kx$ and $\sin(-kx)=-\sin kx$. Products: even$\cdot$even and odd$\cdot$odd are even; even$\cdot$odd is odd.

Lemma

Let $g$ be integrable on $[-L,L]$. Split $\int_{-L}^{L}g=\int_{-L}^{0}g+\int_0^Lg$ and substitute $u=-x$, $du=-dx$ in the first piece; the limits $x=-L\to0$ become $u=L\to0$:

$$ \int_{-L}^{0}g(x)\,dx=\int_{L}^{0}g(-u)(-du)=\int_0^Lg(-u)\,du. $$

Hence $\int_{-L}^{L}g=\int_0^L\left[g(x)+g(-x)\right]dx$. If $g$ is even this equals $2\int_0^Lg$; if $g$ is odd the bracket is $0$ and $\int_{-L}^{L}g=0$.

Step-by-Step Result
Even $f$

$f\cos kx$ is even (even$\cdot$even), so $a_n=\frac2L\int_0^Lf\cos kx\,dx$ and $a_0=\frac1L\int_0^Lf\,dx$. $f\sin kx$ is odd, so $b_n=0$ for all $n$. The series is a cosine series:

$$ f(x)\sim a_0+\sum_{n=1}^{\infty}a_n\cos\frac{n\pi x}{L}. $$

Odd $f$

$f\cos kx$ is odd, so $a_n=0$ and $a_0=0$ (the integrand $f$ is odd). $f\sin kx$ is even, so $b_n=\frac2L\int_0^Lf\sin kx\,dx$. The series is a sine series:

$$ f(x)\sim\sum_{n=1}^{\infty}b_n\sin\frac{n\pi x}{L}. $$

Fourier Series, Convergence and Checks
Answer

A $2L$-periodic even function has only cosines (and a constant); an odd one has only sines. Coefficients need integration over $[0,L]$ only, doubled.

Parity of derivatives and integrals (chain rule): if $f$ is even, differentiate $f(-x)=f(x)$: $-f'(-x)=f'(x)$, so $f'$ is odd; if $f$ is odd, $-f'(-x)=-f'(x)$, so $f'$ is even. For $F(x)=\int_0^xf(s)ds$, substitution $s=-t$ gives $F(-x)=\int_0^{-x}f(s)ds=-\int_0^{x}f(-t)dt$, so $F$ is odd when $f$ is even and even when $f$ is odd. This explains why term-by-term differentiation of a cosine series gives a sine series and conversely.

Endpoint conditions

If $f$ is odd and continuous at $0$, then $f(0)=-f(0)$, so $f(0)=0$; by $2L$-periodicity $f(L)=f(-L)=-f(L)$, so $f(L)=0$ (and $f(\pm L)=0$). If $f$ has a jump there, the series converges to the average $\tfrac12[f(0^+)+f(0^-)]=0$ (and $0$ at $\pm L$), matching the vanishing of every $\sin\frac{n\pi x}L$. For an even $f$, $f(L)=f(-L)$ holds automatically, so the periodic extension has no jump at $\pm L$; if $f$ is also differentiable, $f'$ is odd, hence $f'(0)=f'(L)=0$ (flat ends), compatible with $\cos$ having zero slope there.

Examples in this chapter: $|x|$ and $x^2$ (cosine series) and $x$ (sine series) in Problem - Ch6-P5 Fourier Series of Nine Functions; $x^2$ with general $L$ in Problem - Ch6-P8 Sketching Fourier Series and Periodic Extensions. The relation to half-range expansions is the same lemma: extend a function given on $[0,L]$ evenly (cosine series) or oddly (sine series).
